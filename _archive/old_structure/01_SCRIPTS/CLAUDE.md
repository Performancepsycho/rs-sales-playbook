## فلسفة السكريبتات في RS

### 1) السكريبت = هيكل + توقيع شخصي
- الهيكل (opening, discovery, pitch, close) موحّد
- الكلام نفسه = توقيع كل سيلز (اللهجة، إيقاع كلامه)
- النتيجة: consistency في الجودة، personality في التواصل

### 2) Brief-Driven, مش Generic
- قبل أي رسالة، السيلز لازم يقرأ الـ brief من الـ AI Agent
- السكريبت بيتعدل حسب:
  - الورشة (محتوى مختلف لكل ورشة)
  - مستوى العميل (fresh / junior / senior)
  - مستوى الـ lead (warm / hot)
  - الـ objection اللي ممكن يطلع

### 3) الواتساب مش زي الكول
- **واتساب:** قصير، نقطي، فيه emoji محسوب، بـ links مباشرة
- **كول:** discovery أعمق، tonality أدفى، closing أوضح
- **ميسنجر:** زي واتساب بس tone أرسمي شوية (الجمهور أصغر سناً عادةً)

### 4) Hook في أول 7 ثواني / 7 كلمات
- الـ opening لازم يحرك مشاعر/فضول/ارتباط
- مفيش "أهلاً، إزيك، أتمنى تكون بخير، أنا فلانة من فلان" — ده waste
- الصح: "محمد، أهلاً 👋 شفت إنك بتسأل عن ورشة الضرائب — حابب أوضحلك حاجة مش في الإعلان"

## Sales Cycle المثالي على واتساب

```
T = 0     → الـ Lead بيوصل للسيلز (بعد 2 ساعة من آخر رسالة لـ AI Agent)
T + 5min  → السيلز يقرأ الـ brief كامل
T + 30min → أول رسالة (warm opener + acknowledgment للـ context)
T + 2h    → لو مفيش رد: رسالة 2 (قيمة محددة، مش "ايه أخبارك")
T + 24h   → كول (لو مفيش رد على الواتساب)
T + 48h   → رسالة 3 (آخر محاولة قبل ما يرجع للـ nurture)
T + 7d    → لو لسه silent: تحويل لـ AI Agent للـ long-term nurture
```

## Output Format لأي سكريبت جديد

```markdown

## الجمهور المستهدف
[Fresh / Junior / Senior / Manager]

## الـ Pain Point اللي بنخاطبه
[واحد محدد، مش قايمة]

## الـ Hook (أول 7 ثواني/كلمات)
[الرسالة الأولى]

## Discovery (3-5 أسئلة)
1. ...
2. ...

## الـ Pitch (لو هو جاهز)
[القيمة، مش المحتوى]

## الـ Close
[CTA واحد واضح]

## Variations
- لو رد بـ X → ...
- لو رد بـ Y → ...
- لو سكت → follow-up template

## ❌ Anti-pattern
[ما تعملش كده وليه]
```
