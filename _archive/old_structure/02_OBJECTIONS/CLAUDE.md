## فلسفة التعامل مع الاعتراض

### قاعدة #1: الاعتراض = اهتمام
العميل اللي بيعترض = العميل اللي بيفكر يشتري. العميل اللي مش بيعترض هو اللي بيمشي بصمت.

### قاعدة #2: ورا كل اعتراض ظاهري، فيه اعتراض حقيقي
- "غالية" نادراً معناها السعر فعلاً — أكتر معناها "مش مقتنع بالقيمة"
- "هفكر" نادراً معناها هيفكر — معناها "في حاجة قلقاني وما قلتلكش عليها"
- "هكلم زوجتي/أهلي" ممكن يكون حقيقي + ممكن يكون stalling

### قاعدة #3: A.C.R Framework
```
A — Acknowledge (اعترف بالاعتراض، مش جدال)
C — Clarify (اسأل سؤال يفهم الاعتراض الحقيقي)
R — Respond (رد بـ datapoint، مش جدال)
```

**❌ غلط:** "لأ مش غالية، تفتكر [منافس] أرخص؟ بس..."
**✅ صح:** "أتفهم. السعر مهم، خصوصاً لو محدش وضّحلك القيمة بشكل واضح. ممكن أسألك: هو السعر نفسه عالي عليك دلوقتي، ولا انت مش حاسس إن الورشة هتجيب ضعفه؟"

### قاعدة #4: Premature Discount = Death of Deal
العميل لو طلب خصم وانت أعطيت → اتعلم إنك بتنزل، هيطلب أكتر. ولو رفضت → الـ trust يضعف. لازم يبقى في **سبب واضح** للخصم (مجموعة، early bird، fresh graduate package).

## Quick Reference — السكيكة (Cheat Sheet)

> السيلز يحتاجها على الموبايل أثناء المكالمة.

```
"غالية" 
→ "أتفهم. هو السعر نفسه عالي عليك ولا حضرتك مش حاسس بقيمة الورشة؟"

"ممكن خصم؟" 
→ "في 3 أنواع خصومات — مجموعة، fresh، early bird. أنت في أنهم؟"

"هفكر"
→ "تمام. في حاجة محددة قلقاني؟ السعر؟ التوقيت؟ ولا حاجة تانية؟"

"هكلم زوجتي/أهلي"
→ "محترمة. ايه اللي محتاج تتأكد منه قبل ما تكلمهم؟"

"مش هلحق المواعيد"
→ "في ورشة تانية موعدها بيختلف، أو خيار أونلاين. عاوز أعرف انت متاح امتى؟"

"هل ضامن شغل؟"
→ "مفيش حد بيضمن شغل. اللي بنضمنه: portfolio + skills تخلي إنترفيو واحد كافي."

"أنا في محافظة"
→ "أونلاين متاح. الفصول live بنفس التفاعل."

"بفكر في كورس تاني"
→ "كويس إنك بتقارن. ممكن تقولي ايه اللي بيجذبك في الكورس التاني؟ عشان أعرف لو ينفع نضيفه أو نوضح حاجة."

"مش متأكد إنها هتفرق"
→ "أتفهم. ممكن أوصلك بمتدرب قديم في نفس وضعك تكلمه مباشرة؟"

"هل المحاضر يعرف؟"
→ "[اسم المحاضر] شغّال [دوره الحالي] في [الشركة]. مش بيدرّس نظري، بيدرّس شغله."
```

## Recovery من اعتراض حاد

أحياناً العميل بيعترض بحدة ("الموضوع كله نصب"، "بقالي 6 شهور أسأل ومحدش رد"). الاستجابة:

```
1. ما تدافعش — "أتفهم تماماً"
2. اعرف الـ root cause — "ممكن تقولي إيه اللي حصل بالظبط؟"
3. اعتذر لو المسؤولية علينا — "صح كده ده تقصير منا"
4. حل ملموس — "هعمل [حاجة محددة] دلوقتي"
5. Follow-up شخصي — "هكلمك بنفسي بكره الساعة 11"
```

## ❌ ممنوع نهائياً

1. **الجدال:** "لأ، مش غالية" — العميل بيتعصب ويغلق
2. **التقليل من الاعتراض:** "ده موضوع بسيط" — احترام الـ concern مهم
3. **مقارنة سيئة بمنافسين** بالاسم — غير مهني
4. **خصم لأي حد طلب** — يكسر السعر للجميع
5. **توعيد بحاجة الورشة مش بتعملها** — refunds + سمعة سيئة
6. **استخدام scarcity كاذب** — "آخر مقعدين" لو مش حقيقي
