## فلسفة التقارير

1. **التقرير = قرار، مش معلومة** — لو مفيش action، التقرير مش يستحق الوقت
2. **Numbers + Story** — "Conversion 18%" بدون "ليه" = noise
3. **Visual > Tabular > Text** — Charts للـ trends
4. **Self-Serve > Pulled** — السيلز يدخل Odoo يشوف بنفسه
