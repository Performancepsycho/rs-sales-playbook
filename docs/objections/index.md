# 🛡️ معالجة الاعتراضات

> الاعتراض = اهتمام. العميل اللي بـ يعترض = اللي بـ يفكر يشتري. اللي بـ يقفل بصمت = اللي مش هـ يشتري.

---

## فلسفة A.C.R

```
A — Acknowledge (اعترف بالاعتراض، مش جدال)
C — Clarify (اسأل سؤال يفهم الاعتراض الحقيقي)
R — Respond (رد بـ datapoint أو حل، مش جدال)
```

**❌ غلط:** "لأ مش غالية، تفتكر [منافس] أرخص؟ بس..."

**✅ صح:** "أنا فاهمك. السعر مهم. خليني أسألك: السعر نفسه عالي عليك، ولا انت مش حاسس إن الورشة هـ تجيب ضعفه؟"

## Quick Reference Cheat Sheet (للموبايل أثناء المكالمة)

> 30 رد سريع للـ objections الأكتر شيوعاً. كل category له تفاصيل أعمق في الـ section بتاعه.

### 💰 السعر
```
"غالية"
→ Clarify: "السعر نفسه صعب دلوقتي، ولا مش حاسس إنها بـ تساوي؟"
→ صعب: 50/50 بدون فوايد + تقسيط بنكي + كل وسائل الدفع
→ مش بـ تساوي: ROI بـ data + portfolio + متخرج fresh اتقبل في 3 شركات

"ممكن خصم؟"
→ "3 أنواع رسمية: مجموعة، fresh، early bird. انت في أنهم؟"
→ مفيش خصم individual، بدل منه 50/50

"يوتيوب مجاني"
→ "كام محاسب اتعلم من يوتيوب لوحده وبقى محترف؟"
→ Table: theory vs practice + portfolio + feedback + network

"الفلوس مش معايا"
→ Clarify: "الشهر ده، ولا مش هـ تيجي قريباً؟"
→ الشهر ده: 3 خيارات (جدية رمزية / تأجيل / تقسيط بنكي)
→ مش قريباً: priority list + احترام
```

### 🚧 Stalling
```
"هفكر"
→ Clarify: "في حاجة محددة شاغلاك؟ سعر/توقيت/محاضر؟"
→ Scale 1-10 → "إيه اللي مخلّيش الرقم 10؟"

"هكلم زوجتي/أهلي"
→ "متوقع يسألوك إيه؟" → جاوب الأسئلة قبل ما يسألوها
→ "لو قالوا 'احجز'، هـ تحجز ولا في حاجة تانية؟"

"هرجعلك"
→ ميعاد محدد: "الخميس 7م؟"
→ Reminder + حاجة يـ راجعها قبلها

"بعد العيد"
→ جدية رمزية 500ج تأمّن مقعد المجموعة الجاية
→ 70% بـ يـ ختفوا لو ما اتـ خدش commitment
```

### 🤔 الثقة
```
"هل ضامن شغل؟"
→ "مفيش حد بـ يضمن شغل بـ عقد. اللي بنضمنه: portfolio + skills"
→ Data: 7-8/10 بـ يشتغلوا في 3 شهور (12 سنة شغل، 50,000+ متدرب)

"المحاضر يعرف؟"
→ Permission: "تـ فضّل LinkedIn، مكالمة مع المحاضر، ولا متدرب قديم؟"

"اتشحبطت قبل كده"
→ "احكيلي إيه اللي حصل" → اسمع بدون مقاطعة
→ Differentiator حسب القصة + 7-day money-back

"Refund policy؟"
→ "7 أيام = 100%. بعد 3 محاضرات = نسبة. بعد النص = لأ"
→ موضح في عقد التسجيل (ورق، مش كلام)
```

### ⏰ الوقت
```
"مش هلحق المواعيد"
→ Clarify: "يوم محدد؟ الساعة؟ ولا الـ timing عام؟"
→ 3 بدائل: مجموعة تانية، Online، Weekend

"ضغط شغل"
→ "الضغط هـ ينتهي امتى؟"
→ <شهرين: جدية رمزية للمجموعة الجاية
→ long-term: nurture list + goodwill

"الورشة طويلة"
→ Clarify: "خايف ما لتزمش، ولا الـ workload الحالي مش بـ يـ ستوعب؟"
→ Recording لو فات + 7-day money-back

"محاضرة 3 ساعات"
→ Reveal structure (45 شرح + 30 practice + 15 Q&A + 30 group + 30 feedback + 15 wrap)
→ مش 3 ساعات نظري متواصل
```

### 📍 Logistics
```
"أنا في محافظة"
→ Clarify: "internet كويس ولا متقطع؟"
→ Online Live / Recording / Hybrid 3-4 أيام

"ما عنديش لاب توب"
→ Practical: مكتبة / استعارة / شراء used 4000-6000ج
→ ابدأ الورشة، اشتري من فلوس الشغل

"Online مش هـ ينفع"
→ Free demo session (RS Online ≠ default: 25-30 شخص، camera-on)
→ لو ما عجبكش، رد بـ "مش مناسب" بدون ضغط

"في مكان حضور استثنائي في [محافظة]؟"
→ Online + متدرب قديم من نفس المحافظة يحكي تجربته
→ الإسكندرية = مكان استثنائي للمحاسب الشامل 6 يونيو فقط
```

### 🥊 Competition
```
"بفكر في [منافس]"
→ Clarify: "إيه الـ specific اللي بـ يجذبك؟ سعر/محاضر/محتوى/مدة؟"
→ جاوب على النقطة دي تحديداً، مش generic RS pitch

"[منافس] أرخص"
→ Price-per-hour comparison (مش total price)
→ الفرق بـ يـ غطّي: مجموعة 25-30 + تطبيق شركات حقيقية + فيدباك شخصي

"[منافس] بـ يضمن شغل"
→ "اطلب منهم عقد مكتوب بـ refund clause لو ما حصلش placement"
→ 95% بـ يـ تراجعوا + RS data: 7-8/10 في 3 شهور

"إعلانات [منافس] أحسن"
→ "بـ تشتري الـ marketing، ولا الـ workshop؟"
→ مكالمة مجانية مع المحاضر، الـ ads بـ تـ بالغ عادة
```

### ❓ Doubt
```
"مش هـ تفرق معايا"
→ Clarify: "Past pain / self-doubt / mismatch fear؟" → personalize الرد
→ مش بـ يـ تحل بـ pitch، بـ يـ تحل بـ reflection

"حد حضر وما اتفرّق"
→ 3 أسئلة عن الشخص (حضور / assignments / تطبيق)
→ غالباً الـ issue implementation مش الورشة

"مش هـ لتزم"
→ Diagnostic: accountability / value / effort / life crisis
→ RS بـ يـ ساعد في accountability (assignments + group + 1-on-1)

"بعرف الـ content"
→ Quick 5-question test → honest recommendation
→ لو 4+ بـ ثقة: ارفض البيع. لو 0-1: الورشة بـ تـ ناسبه
```

## Recovery من اعتراض حاد

أحياناً العميل بـ يعترض بحدة ("الموضوع كله نصب"، "بقالي 6 شهور أسأل ومحدش رد"). الاستجابة:

```
1. ما تدافعش: "أنا فاهمك، الـ delay ده تقصير منّا"
2. اعرف الـ root cause: "ممكن تقولي إيه اللي حصل بالظبط؟"
3. اعتذر لو المسؤولية علينا: "صح كده، ده غلطنا"
4. حل ملموس: "هعمل [حاجة محددة] دلوقتي"
5. Follow-up شخصي: "هكلمك بنفسي بكره الساعة 11"
```

تفاصيل أعمق في [trust.md](trust.md)، قسم "محدش رد عليّ".

## ❌ ❌ ❌ Anti-Patterns الخطرة (عابرة كل category)

1. **الجدال:** "لأ، مش غالية"، العميل بـ يتعصب ويغلق
2. **التقليل من الاعتراض:** "ده موضوع بسيط"، احترام الـ concern مهم
3. **مقارنة سيئة بمنافسين بالاسم:** غير مهني + بـ يخسرك ثقة
4. **خصم لأي حد بـ يطلب:** بـ يكسر السعر للجميع
5. **توعيد بحاجة الورشة مش بـ تعملها:** refunds + سمعة سيئة
6. **استخدام scarcity كاذب:** "آخر مقعدين" لو مش حقيقي
7. **تجاهل الـ past pain:** العميل بـ يحس إنك مش بتسمع
8. **Generic responses:** كل اعتراض محتاج personalization


**Insight أسبوعي للـ Director:**

- أكتر objection type بـ يخسر فيه الفريق؟ → coaching gap
- أكتر objection بـ يحصل في أنهي ورشة؟ → marketing positioning gap
- أي سيلز بـ يتعامل مع objection محدد أحسن من غيره؟ → ده الـ peer trainer
