## بنية كل ورشة

كل ورشة فيها:
- **3 Angles** — حسب نوع العميل (مين هو، إيه pain اللي عنده)
- **7 Stages** — حسب اللي عمله الـ AI Agent مع العميل قبل ما يوصل لك

```
الورشة
  ├── Angle 1 (نوع عميل أول)
  │   ├── Stage 1: تم التحويل
  │   ├── Stage 2: تم الحجز
  │   ├── Stage 3: جاهز للتحويل
  │   ├── Stage 4: مهتم لم يتقدم
  │   ├── Stage 5: شاف السعر ولم يحجز
  │   ├── Stage 6: الاستكشاف
  │   └── Stage 7: رفض
  ├── Angle 2 (نوع عميل تاني)
  │   └── ... نفس الـ 7 stages
  └── Angle 3 (نوع عميل تالت)
      └── ... نفس الـ 7 stages
```

كل Stage فيه:
- 📱 **سكريبت WhatsApp** (opener + follow-ups)
- 📞 **سكريبت Call** (هيكل + كلمات + responses)
- ⚠️ **Anti-patterns** للتجنب
