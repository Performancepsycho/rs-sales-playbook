# 🎯 Angle 3: صاحب شركة بيدفع غرامات ضريبية

> **الجمهور:** صاحب شركة (صغيرة-متوسطة). دفع غرامات ضريبية أكتر من مرة. مش راضي يفضل يدفع غرامات بدون فهم.
> **الـ Pain:** "كل سنة بدفع غرامات. محاسبي بيقولي 'لازم'. مش متأكد إذا فعلاً لازم ولا فيه إهمال."
> **الـ Hook:** "تفهم ضرايب شركتك بنفسك = تمنع الغرامات + توفّر فلوس + تتحقق من شغل محاسبك"

---

## 📋 Quick Reference

| العنصر | المحتوى |
|--------|---------|
| **اسم الورشة** | خبير الضرائب |
| **المحاضر** | أ/ أحمد علي |
| **المدة** | 12 محاضرة × 3 ساعات |
| **الـ Pain** | "بدفع غرامات + مش فاهم ضرايب شركتي" |
| **الـ Promise** | "تتحول من passive (بتدفع) لـ proactive (بتمنع)" |
| **Top 3 Objections** | (1) "أنا مش محاسب" (2) "12 محاضرة كتير على شغلي" (3) السعر |

# Stage 4: مهتم - لم يتقدم (🟡 Warm)

### 📱 WhatsApp — الـ Opener
```
[الاسم] أهلاً 👋

عرفت السعر لورشة خبير الضرائب وقلت "تمام".

سؤال صريح كصاحب شركة:

ايه القلق الحقيقي؟

A) "أنا مش محاسب — الورشة عميقة عليّ"
B) "12 محاضرة وقت كبير على جدولي"
C) "السعر — مش متأكد من الـ ROI"
D) "محاسبي بيتولى الموضوع"

أيهم؟
```

#### Follow-up (لو "A — مش محاسب")
```
سؤال صح.

الورشة بتبدأ من الصفر. بس فيها مفهومات ضريبية تحتاج تركيز. أصحاب الشركات اللي حضروا بيقولوا:
- المحاضرات الأولى (1-3) صعبة شوية
- بعدها بيبدأ يتركّب — هتلاقي نفسك بتفهم اللي محاسبك بيقوله
- بحلول المحاضرة 6-7، هتسأل أسئلة محاسبك ما يقدرش يجاوبها بدون verification

اقتراح: تحب أوصلك بصاحب شركة قديم حضر؟
```

#### Follow-up (لو "D — محاسبي يتولى")
```
سؤال صريح:

كم غرامة ضريبية دفعتها في آخر 3 سنين؟

لو الإجابة 0 → محاسبك ممتاز، الورشة insurance لتأكيد ده.
لو الإجابة في غرامات → الورشة هتديك القدرة تـ verify محاسبك + تمنع غرامات قادمة.

غرامة واحدة بـ 50,000ج = ضعف سعر الورشة 5 مرات.
```

### 📞 Call
```
"[الاسم] — عرفت السعر لخبير الضرائب وقلت 'تمام'. كلمتك نفهم.

سؤال صريح كصاحب شركة: 'مش محاسب'؟ 'وقت'؟ 'محاسبي يكفّيني'؟

[Branch]"
```

[Branch — لو فيه pain فعلي، اربط بقيمة الورشة]"

# Stage 6: مرحلة الاستكشاف (🔵 Cold)

### 📱 WhatsApp — الـ Opener
```

سؤال قبل ما أبعتلك التفاصيل:

أنت بتسأل لنفسك (صاحب شركة) ولا للموظف بتاعك (محاسب)؟

(الـ approach مختلف — أصحاب الشركات بيركزوا على verification + cost saving، الموظفين بيركزوا على specialization)
```

### 📞 Call
```
"[الاسم] — كنت بتسأل عن خبير الضرائب. ناخد 10 دقايق نفهم وضعك؟

Discovery:
1. شركتك في إيه؟ بقالها قد إيه؟
2. عندك محاسب داخلي ولا office محاسبة بيشتغل؟
3. آخر سنتين، كم غرامات ضريبية دفعت؟
4. ايه أكبر سؤال ضريبي مش متأكد منه دلوقتي؟

[Pitch focused on owner ROI angle]"
```

# Stage 7: رفض (🔵 Cold)

### 📱 WhatsApp — الـ Opener
```
[الاسم] أهلاً 👋

شفت إنك قلت إن الورشة مش مناسبة. احترم.

سؤال أخير:

ايه السبب؟

A) "12 محاضرة كتير"
B) "السعر"
C) "محاسبي بيكفّيني"
D) "أكتفي بمستواي الحالي"

أيهم؟
```

#### Follow-up (لو "C — محاسبي بيكفّيني")
```
سؤال محايد:

في 5 سنين، هل آمن إنك تعتمد 100% على شخص واحد بدون verification؟

ايه يحصل لو:
- محاسبك غاب وقت موسم الضرايب؟
- محاسبك سرقك بدون ما تكتشف؟
- المصلحة عملت فحص ومحاسبك ما عرفش يدافع صح؟

الورشة insurance — حماية لشركتك من خسائر كبيرة. مش بدل محاسبك، بل verification.
```

### 📞 Call
```
"[الاسم] — مش هحاول أقنعك. كلمتك بسؤال:

ايه السبب الحقيقي؟

[Goodwill close]"
```

## ❌ Anti-patterns لـ Angle 3

| ❌ ما تعملش | ✅ بدلها |
|-------------|---------|
| pitch "هتشتغل tax specialist" — هو صاحب شركة | "هتفهم وتحاسب محاسبك" |
| تخوّفه من الغرامات بشكل مبالغ | اشرح الـ insurance angle بهدوء |
| تستخدم مصطلحات تقنية | كلامة business + ROI |
| تقلل من محاسبه | اعترف بدوره + اشرح الـ verification |
