# 📔 ورشة التحليل المالي — Sales Playbook

> **المحاضر:** أ/ أحمد عاشور
> **المدة:** 8 محاضرات حضوري / 5 أونلاين × 3 ساعات
> **الجمهور:** Senior + Managers + رؤساء حسابات + مستثمرين/أصحاب
> **⚠️ متطلب:** اللابتوب الشخصي
> **اللي يميزها:** قراءة + تحليل القوائم المالية + اتخاذ قرارات استراتيجية

---

## 📝 ملخص الورشة

### الـ Hook المركزي
> "تتحول من 'محاسب يعمل قوائم' لـ 'محلل بيقدّم قرارات للإدارة'"

### Differentiators
1. **النسب المالية + التحليل التمويلي** الكامل
2. **اتخاذ قرارات: توسع، تقييم شركة، تحديد قيمة حقيقية**
3. **التحليل التعادلي + التشغيلي**
4. **المحاضر شغّال CFO** — أ/ أحمد عاشور
