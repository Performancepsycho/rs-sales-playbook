# 📔 ورشة التحليل المالي

> **تتحول من 'محاسب يعمل قوائم' لـ 'محلل بيقدّم قرارات للإدارة'.**

---

## 🎯 الـ Hook الرسمي

> **"النسب المالية + التحليل التمويلي + اتخاذ قرارات استراتيجية — ورشة الـ Senior accountants."**

ورشة متخصصة في التحليل المالي للقوائم المالية واتخاذ القرارات المالية والإدارية.

⚠️ **متطلب:** اللابتوب الشخصي.

---

## ✅ اللي هتطلع منها قادر تعمله

=== "🎯 Outcomes الـ 5"

    1. ✅ **قراءة وفهم وتحليل** القوائم المالية + تقييم الأداء
    2. ✅ **الكشف عن جوانب الضعف** + اتخاذ القرارات
    3. ✅ **وضع السياسات والبرامج** المستقبلية
    4. ✅ **تقييم أداء الإدارة العليا**
    5. ✅ **تقييم كفاءة الإدارة** في استخدام موارد الشركة

=== "📚 المحاور"

    - أهمية القوائم المالية + إعادة معالجتها للتحليل
    - النسب المالية الكاملة
    - التحليل التمويلي الشامل + التخطيط المستقبلي
    - السياسات الخاصة بالتوسع والفصل
    - تحديد قيمة الشركة الحقيقية + المركز المالي
    - تحديد القدرة الربحية + كفاءة النشاط
    - التحليل التعادلي + التشغيلي

## 🛡️ أكتر اعتراضات بتطلع

??? question "هل دي عميقة عليّ؟"
    "الورشة بتفترض base محاسبية. لو senior accountant — هي الخطوة المنطقية بعدك. لو junior — اقترح تكمل خبرة سنة على الأقل قبل."

??? question "بفكر في CFA / FMVA بدلاً منها"
    "Complementary مش competing. CFA = 2-4 سنين. ورشتنا = 7 محاضرات + بالعربي + المحاضر مصري CFO. الـ best path: ورشتنا دلوقتي + CFA على المدى الطويل."

??? question "هل ينفع أتعلم من YouTube؟"
    "YouTube بيشرح 'إيه نسبة السيولة'. الورشة بتديك 'متى تستخدمها + ايه interpretation + ايه التوصية'. الفرق = محاسب vs محلل."
