# 🎯 Angle 2: محلل junior عاوز يطلع senior

> **الجمهور:** محلل مالي junior (1-3 سنين). شغّال في تحليل بس على مستوى أساسي. عاوز يطلع senior analyst أو financial planner.
> **الـ Pain:** "أنا بعمل التحليلات الأساسية بس senior بياخدها ويعمل عليها التوصيات. عاوز أبقى أنا اللي يقدّم القرارات."
> **الـ Hook:** "تنتقل من 'بيحسب نسب' لـ 'بياخد قرارات' = الفرق بين junior و senior analyst"

---

| العنصر | المحتوى |

# Stage 4: مهتم - لم يتقدم (🟡 Warm)

### 📱 WhatsApp — الـ Opener
```
[الاسم] أهلاً 👋

عرفت السعر للتحليل المالي وقلت "تمام". سؤال صريح:

A) "هل دي بتسبق خبرتي؟ (أنا junior)"
B) "السعر"
C) "بفضل تخصص في industry معين بدلاً من 'تحليل عام'"
D) "الوقت"

أيهم؟
```

#### Follow-up (لو "A — بتسبق خبرتي")
```
سؤال صح.

الورشة بتفترض base محاسبي بسيط (عندك). الفرق إنها بتعلمك الـ tools اللي بيستخدمها الـ senior analyst.

الـ approach الصح:
1. تحضر الورشة دلوقتي (تتعلم الـ tools)
2. تطبقهم في شغلك الحالي تدريجياً
3. في 6-12 شهر، تكون عندك practical experience + theoretical foundation
4. = senior analyst ready

العكس: تستنى لما تطلع senior وتحضر الورشة → بيكون بطيء + بدون structure.
```

#### Follow-up (لو "C — أتخصص في industry")
```
سؤال ذكي.

الواقع: التحليل المالي أساس لكل industry. بعد ما تعرف الـ fundamentals، التخصص بياخد 3-6 شهور.

الـ approach: ابدأ بالتحليل المالي العام (الورشة دي) → بعدها تخصص في صناعة (real estate, banking, FMCG, إلخ) في شغلك العملي.

الفعل العكسي = تخصص في صناعة بدون foundation = هتلاقي نفسك تايه.
```

### 📞 Call
```
"[الاسم] — عرفت السعر للتحليل المالي وقلت 'تمام'. كلمتك نفهم.

سؤال صريح: 'بتسبق خبرتي'؟ 'تخصص في industry'؟ السعر؟

[Branch]"
```

# Stage 5: شاف السعر ولم يحجز (🟡 Warm)

### 📱 WhatsApp — الـ Opener
```
[الاسم] أهلاً 👋

من 3 أيام، عرفت تفاصيل التحليل المالي. وقلت "هفكر".

1️⃣ "هفكر هحجز قريب"
2️⃣ "هفكر بدور على CFA / FMVA"
3️⃣ "هفكر مش الوقت المناسب"
4️⃣ "هفكر مش هحجز"

كلمة واحدة.
```

#### Follow-up (لو "2 — CFA / FMVA")
```
كويس إنك بتقارن بـ certifications international.

الواقع:
- **CFA:** 2-4 سنين دراسة + 3 امتحانات + باهظة (3000-5000$). لكن متعارفة عالمياً.
- **FMVA:** أرخص + أسرع. بس pdf + videos. لـ self-study.
- **ورشتنا:** عملية + بـ محاضر شغّال CFO + 24 ساعة + بالعربي + تطبيق على شركات مصرية.

الـ best path:
- لو طموحك Egypt-focused → الورشة دي + خبرة عملية = الأفضل
- لو طموحك international → CFA على 3 سنين، الورشة كـ foundation
- مش "أو" — هما complementary

عاوز نتكلم 5 دقايق نظبط الـ best path ليك؟
```

### 📞 Call
```
"[الاسم] — عرفت تفاصيل التحليل المالي وقلت 'هفكر'. ناخد 5 دقايق؟

سؤال: لو خلصت + بدأت تقدم تحليلات بمستوى senior في 6 شهور، هتحضر دلوقتي؟

[Branch]"
```

## ❌ Anti-patterns لـ Angle 2

| ❌ ما تعملش | ✅ بدلها |
|-------------|---------|
| تستهتر بـ CFA/FMVA كبدائل | اعترف بمكانتهم + اشرح ليه الورشة complementary |
| pitch generic عن "تحليل" | اربط بـ junior → senior progression |
| تنسى الـ laptop requirement | ذكّر |
| تجاهل الـ industry specialization angle | اعترض بـ "foundation الأول، تخصص بعدين" |
