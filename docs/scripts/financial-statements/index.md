## 🛡️ اعتراضات خاصة بورشة إعداد القوائم

??? warning "\"إيه الفرق بينها والمحاسب المالي؟ ليه أدفع 2500 بدل 3250؟\""

    **R:** القوائم **focused** = 5 محاضرات فقط على القوائم. المالي = الدورة كاملة (8 محاضرات).

    لو فريش/junior بدون أساس → **المالي 3250ج**.
    لو شغّال 1-2 سنة + بـ تـ عمل قيود + عاوز focused → **القوائم 2500ج**.

??? warning "\"5 محاضرات قليلة\""

    **R:** الـ focused intentional. 15 ساعة تطبيق على القوائم فقط = case study حقيقية + 4 أنواع قوائم + EAS + قوالب جاهزة.

    لو عاوز أعمق (التسويات + القروض + التسوية البنكية)، اخد **الشامل (32 ساعة)** بـ 5800ج.

??? warning "\"عندي أساس بسيط — هل أقدر؟\""

    **R:** نعم. الورشة مصممة للـ junior اللي بـ يـ عرف debit/credit + بـ يـ كتب قيود + بـ يـ ميز الأصول والخصوم. ده base كافي.

    لو فريش 100%، اخد **المالي** أولاً.

??? warning "\"صاحب شركة — هل ينفعني؟\""

    **R:** نعم. تـ قرأ قوائم محاسبك + تـ كتشف أخطاء + تـ تـ خد قرارات بـ data + تـ تـ كلم مع البنك بـ ثقة.

    **توصية:** ضيف Excel = bundle **4500ج**.

??? warning "\"بـ تـ تـ علم قائمة التدفقات النقدية؟\""

    **R:** نعم. كل الـ 4 قوائم (الدخل + المركز + **التدفقات** + الإيضاحات). التدفقات في المحاضرة 4-5 بـ كل الـ 3 أنشطة (تشغيلية + استثمارية + تـ مويلية).

??? warning "\"بـ تـ غطى EAS standards؟\""

    **R:** نعم. EAS 1 + EAS 2 (overview) + EAS 10 + EAS 16 + EAS 17. من منظور **عملي** — مش academic.
