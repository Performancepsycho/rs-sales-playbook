# 📊 ورشة إعداد القوائم المالية

> **الورشة الـ Focused — تطلع من الورشة قادر تعمل قوائم مالية كاملة لأي شركة في 5 محاضرات بس.**

---

## 🎯 الـ Hook الرسمي للورشة

> **"5 محاضرات × 3 ساعات = القدرة الكاملة على إعداد قائمة الدخل، قائمة المركز المالي، والإيضاحات المتممة لأي شركة."**

دي ورشة **متخصصة + سريعة** — مش كل المحاسبة من الصفر، بس **الجزء الذي السيلز محتاجه ليتم احترافياً: إعداد القوائم المالية**.

---

## ✅ اللي هتطلع منها قادر تعمله

=== "📊 إعداد القوائم بأنواعها"

    - ✅ **قائمة الدخل** — الإيرادات + المصروفات + صافي الربح
    - ✅ **قائمة المركز المالي** (الميزانية) — الأصول + الخصوم + حقوق الملكية
    - ✅ **الإيضاحات المتممة** — ربط القوائم بالتفاصيل
    - ✅ **ميزان المراجعة** — قبل الإعداد النهائي
    - ✅ **التسويات قبل الإقفال** — للوصول للقوائم الصحيحة

=== "🎯 المهارات اللي معاك بعد الورشة"

    1. **Read** — تقرأ أي قائمة مالية وتفهمها
    2. **Build** — تجهّز قوائم لشركة من الصفر
    3. **Verify** — تتحقق من قوائم محاسب آخر
    4. **Communicate** — تشرح الأرقام للإدارة بثقة

## 🎯 ملاحظات هامة للسيلز

### الـ Cross-sell الذكي

ورشة إعداد القوائم **complementary** مع ورش تانية:

- **مع المحاسب المالي:** للفريش بدون base — يبدأ بالمالي ثم القوائم لاحقاً
- **مع التحليل المالي:** القوائم = الـ input، التحليل = الـ output. الاتنين مع بعض = senior analyst
- **مع المحاسب الشامل:** المحاسب الشامل بتشمل القوائم + أكتر — لو وقت العميل يسمح، الشامل أفضل

### الـ Multi-booking المثالي

- **عميل واحد + ورشتين:** "إعداد القوائم + التحليل المالي" = 2000ج + 4000ج = 6000ج (وفّر 1500ج)
- **3 زمايل:** القوائم 2000ج × 3 = 6000ج (وفّر 1500ج)
