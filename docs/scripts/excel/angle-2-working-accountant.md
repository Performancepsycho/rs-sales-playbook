# 🎯 Angle 2: محاسب شغّال بيعمل تقارير

> **الجمهور:** محاسب 2-7 سنين خبرة. شغل Excel-heavy (تقارير شهرية، تحليلات، sheets للإدارة). الـ skills basic-intermediate.
> **الـ Pain:** "بقعد ساعات على تقرير ممكن يخلص في دقايق لو كنت أعرف الـ tools الصح."
> **الـ Hook:** "12 ساعة بترجع لك 100+ ساعة سنوياً — productivity boost حقيقي"

---

## 📋 بطاقة مرجعية سريعة

| العنصر | المحتوى |
|--------|---------|
| **اسم الورشة** | الإكسيل |
| **المحاضر** | أ/ مصطفى القصاص |
| **المدة** | 4 محاضرات × 3 ساعات (12 ساعة) |
| **السعر** | 4000ج → **2000ج** |
| **متطلب** | اللابتوب الشخصي |
| **الـ Pain** | "بضيع ساعات في تقارير manual" |
| **الـ Promise** | "Power Query + Pivot = automation للتقارير الشهرية" |

---

## 📚 الـ 7 Stages

??? danger "Stage 1: تم التحويل ✅💰 (🔥 Hot)"

    ## السياق
    العميل **حوّل**. السيلز يأكد + يرحب + يذكّر باللابتوب.

    ## الهدف
    تأكيد + ترحيب + تسليم تفاصيل

    === "📱 WhatsApp"

        ```
        ✅ التحويل وصل، شكراً [الاسم]!

        🎉 مبروك! حجزك في ورشة الإكسيل مع أ/ مصطفى القصاص مؤكد.

        📋 التفاصيل:
        • التاريخ: 11 مايو 2026
        • المواعيد: الاثنين + الخميس، 6م-9م
        • العنوان: 29 أ امتداد رمسيس، نقابة التجاريين، الدور 8

        ⚠️ **جيب اللابتوب** + **تقارير حقيقية من شغلك** (لو ممكن — مع إخفاء الـ data الحساسة).
        أ/ مصطفى بيحب يطبق على cases real من شغل المتدربين.

        أهلاً بيك! 🌟
        ```

    === "📞 Call"

        ```
        "[الاسم] — مبروك على القرار 🎉

        نصيحة قبل ما أوديك التفاصيل: جيب معاك تقرير شهري من شغلك (مع إخفاء الـ data الحساسة) — أ/ مصطفى هيوريك إزاي تختصر تكوينه من ساعتين لـ 15 دقيقة.

        التاريخ والمواعيد: [التفاصيل]. عندك لابتوب جاهز؟"
        ```

??? danger "Stage 2: تم الحجز ✅ (🔥 Hot)"

    ## السياق
    اتفق على الحجز، لسه ما حوّلش.

    ## الهدف
    timeline للتحويل + لابتوب reminder

    === "📱 WhatsApp"

        ```
        [الاسم] — متفقين على حجز ورشة الإكسيل ([11 مايو]) ✅

        محتاج تحويل **1000ج** جدية حجز:

        🟢 انستا باي: 100057017249
        🟢 فودافون كاش: 01002180432
        🟢 تحويل بنكي: CIB - حساب 100057017249

        أنهي طريقة دفع تناسبك؟ متى تتوقع تحوّل؟

        ⚠️ تذكير: لازم لابتوب شخصي.
        ```

    === "📞 Call"

        ```
        "[الاسم] — متفقين على حجز ورشة الإكسيل. السعر 2000ج، 50% جدية + 50% أول محاضرة.

        أنهي طريقة دفع تفضلها؟ وعندك لابتوب جاهز؟"
        ```

??? danger "Stage 3: جاهز للتحويل 💳 (🔥 Hot)"

    ## السياق
    سأل عن الدفع وما رجعش.

    === "📱 WhatsApp"

        ```
        [الاسم] أهلاً 👋

        شفت إنك سألت قبل كده على طريقة الدفع لورشة الإكسيل.

        في حاجة عمالة تأخر؟

        السعر 2000ج فقط (الأرخص) — جدية الحجز 1000ج بس.

        🟢 انستا باي: 100057017249
        🟢 فودافون كاش: 01002180432

        أنهي يناسبك؟
        ```

    === "📞 Call"

        ```
        "[الاسم] — كلمتك أتأكد إن في حاجة محتاج توضيح. السعر 2000ج، جدية 1000ج. أنهي طريقة دفع أحسن ليك؟"
        ```

??? warning "Stage 4: مهتم - لم يتقدم (🟡 Warm)"

    ## السياق
    شاف السعر، قال "تمام"، ما تحرّكش. الـ objection غالباً: "وقتي ضيق" أو "أنا عارف Excel".

    ## الهدف
    كشف real objection + ربط بـ ROI زمني

    === "📱 WhatsApp"

        ```
        [الاسم] أهلاً 👋

        عرفت السعر لورشة الإكسيل (2000ج) وقلت "تمام". مع السعر ده، الـ objection غالباً مش فلوس.

        سؤال صريح:

        A) "وقتي ضيق" — 4 محاضرات في شهر، الموعد ساعتين بس
        B) "أنا عارف Excel كافي" — اعمل اختبار سريع
        C) "بفكر في وقت تاني" — احطك في list

        أيهم؟
        ```

        #### Follow-up (لو "B — أنا عارف Excel")
        ```
        تمام، 5 أسئلة سريعة:

        1. تعرف XLOOKUP والفرق بينه وبين VLOOKUP؟
        2. تعمل Pivot من 3 sources مختلفة؟
        3. Power Query لاستيراد بيانات من PDF/Web؟
        4. Conditional Formatting بـ formula مش بـ value؟
        5. SUMIFS مع wildcards؟

        لو كل الـ 5 إجاباتها "نعم" → فعلاً مش محتاج. قاعدة 80% من اللي قالوا "أنا عارف Excel" بيقولوا "لأ" على 3+ أسئلة.

        فين أنت؟
        ```

        #### Follow-up (لو "A — وقتي ضيق")
        ```
        12 ساعة في شهر = 3 ساعات/أسبوع. مش كتير لـ skill بترجع لك 5+ ساعات أسبوعياً (lifetime).

        ROI واضح:
        - الورشة: 12 ساعة استثمار
        - بعد الورشة: 5+ ساعات/أسبوع توفير في تقاريرك
        - Break-even: 2-3 أسابيع

        ينفع كده؟
        ```

    === "📞 Call"

        ```
        "[الاسم] — عرفت السعر وقلت 'تمام'. مع 2000ج، الـ objection مش فلوس.

        سؤال صريح: 'وقت'؟ 'مستوايا كافي'؟ 'بفكر'؟

        [Branch — كل واحد رد مفصّل]"
        ```

??? warning "Stage 5: شاف السعر ولم يحجز (🟡 Warm)"

    ## السياق
    قال "هفكر" بعد التفاصيل.

    ## الهدف
    كسر الـ تسويف + commitment

    === "📱 WhatsApp"

        ```
        [الاسم] أهلاً 👋

        من 3 أيام، عرفت تفاصيل ورشة الإكسيل. وقلت "هفكر".

        سؤال محدد:

        1️⃣ "هفكر هحجز قريب"
        2️⃣ "هفكر هحضر cheaper option (Udemy)"
        3️⃣ "هفكر مش الوقت المناسب"
        4️⃣ "هفكر مش هحجز"

        كلمة واحدة.
        ```

    === "📞 Call"

        ```
        "[الاسم] — قلت 'هفكر'. سؤال: لو ضمنّالك إنك في 4 أسابيع هتختصر تقاريرك الشهرية بـ 50%، هتحجز دلوقتي؟"
        ```

??? info "Stage 6: مرحلة الاستكشاف (🔵 Cold)"

    ## السياق
    لسه بيستكشف.

    ## الهدف
    Discovery + ربط بـ pain شغلي

    === "📱 WhatsApp"

        ```
        [الاسم] أهلاً 👋

        شفت إنك بتسأل عن الإكسيل.

        سؤال:

        أنت بتستخدم Excel في شغلك يومياً؟ أصعب جزء بيستهلك وقتك ايه؟

        (تقارير شهرية يدوية؟ مطابقات؟ Pivot معقد؟ Lookup صعب؟)
        ```

    === "📞 Call"

        ```
        "[الاسم] — كنت بتسأل عن الإكسيل. ناخد 7 دقايق نفهم وضعك؟

        1. شغل Excel يومي؟
        2. ايه أصعب tasks بتاخد منك وقت؟
        3. حاولت تتعلم لوحدك (يوتيوب)؟
        4. عملت ROI على وقتك؟"
        ```

??? info "Stage 7: رفض (🔵 Cold)"

    === "📱 WhatsApp"

        ```
        [الاسم] أهلاً 👋

        شفت إنك قلت إن الورشة مش مناسبة. احترم.

        سؤال محايد: لو قعدت 4 ساعات الأسبوع الجاي على تقرير ممكن يخلص في 30 دقيقة، هتفكر تاني؟

        لو نعم → هحطك في list.
        لو لأ → كل التوفيق.
        ```

    === "📞 Call"

        ```
        "[الاسم] — مش هحاول أقنعك. كل التوفيق ليك.

        لو في 6 شهور قررت توفر وقتك في شغلك، كلمني. سلام."
        ```

## ❌ Anti-patterns لـ Angle 2

| ❌ | ✅ |
|----|----|
| pitch generic | اربط بـ pain زمني (ساعات بتضيع) |
| تجاهل Udemy | اعترف + اشرح Live |
| تنسى لابتوب reminder | ذكّر صراحة |

---

## 🚦 شجرة القرار السريعة

```
محاسب شغّال يجي من AI Agent
    ↓
Stages 1-3 → Closing سريع + لابتوب reminder
Stage 4 → Top objection: "أنا عارف Excel" → اختبار سريع 5 أسئلة
Stage 5 → بيقارن بـ Udemy — اشرح الـ Live + الـ ROI الزمني
Stage 6 → Discovery يركز على pain شغلي محدد
Stage 7 → reactivation بـ "ساعات بتضيع" framing
```
