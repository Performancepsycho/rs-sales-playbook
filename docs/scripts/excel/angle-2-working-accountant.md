# 🎯 Angle 2: محاسب شغّال بـ يـ عمل تقارير

> **الجمهور:** محاسب 2-7 سنين خبرة. شغل Excel-heavy (تقارير شهرية، تحليلات، sheets للإدارة). الـ skills basic-intermediate.
> **الـ Pain:** "بـ شتغل في Excel كل يوم بس بـ آخد وقت طويل. مش عارف الـ shortcuts والـ functions اللي بـ تـ وفر ساعات."
> **الـ Hook:** "Excel = اللغة اليومية للمحاسب. لو ضعيف فيها، شغلك بـ ياخد ضعف الوقت — 12 ساعة بـ تـ رجع لك 100+ ساعة سنوياً."

---

## 📋 بطاقة مرجعية سريعة

| العنصر | المحتوى |
|--------|---------|
| **اسم الورشة** | الإكسيل |
| **المحاضر** | أ/ مصطفى القصاص |
| **المدة** | 4 محاضرات × 3 ساعات (12 ساعة) |
| **السعر** | 4000ج → **2000ج** |
| **متطلب** | اللابتوب الشخصي (تطبيق عملي) |
| **الـ Pain** | "بـ ضيع ساعات في تقارير manual" |
| **الـ Promise** | "shortcuts + advanced functions + Pivot + Dashboards = توفير ساعات يومياً" |

---

## 📚 الـ 7 Stages

??? danger "Stage 1: تم التحويل ✅💰 (🔥 Hot)"

    ## السياق
    العميل **حوّل**. السيلز يأكد + يرحب + يذكّر باللابتوب.

    ## الهدف
    تأكيد + ترحيب + تسليم تفاصيل

    === "📱 WhatsApp"

        ```
        ✅ التحويل وصل، شكراً [الاسم]!

        🎉 مبروك، حجزك في ورشة الإكسيل مع أ/ مصطفى القصاص مؤكد.

        📋 التفاصيل:
        🔹 التاريخ: 11 مايو 2026
        🔹 المواعيد: الاثنين + الخميس، 6م-9م
        🔹 العنوان: 29 أ امتداد رمسيس، نقابة التجاريين، الدور 8

        ⚠️ مهم: **جيب اللابتوب** + **تقارير حقيقية من شغلك** (مع إخفاء الـ data الحساسة).
        أ/ مصطفى بـ يـ حب يـ طبّق على cases من شغل المتدربين فعلاً — بـ يـ وريك إزاي تـ ختصر تكوين التقرير من ساعتين لـ 15 دقيقة.

        أهلاً بيك! 🌟
        ```

    === "📞 Call"

        ```
        "[الاسم] — مبروك على القرار 🎉

        نصيحة قبل ما أوديك التفاصيل: جيب معاك تقرير شهري من شغلك (مع إخفاء الـ data الحساسة). أ/ مصطفى هـ يـ وريك إزاي تـ ختصر تكوينه من ساعتين لـ 15 دقيقة بـ Pivot وdefined functions.

        التاريخ والمواعيد: [التفاصيل]. عندك لابتوب جاهز؟"
        ```

??? danger "Stage 2: تم الحجز ✅ (🔥 Hot)"

    ## السياق
    اتفق على الحجز، لسه ما حوّلش.

    ## الهدف
    timeline للتحويل + لابتوب reminder

    === "📱 WhatsApp"

        ```
        [الاسم] — متفقين على حجز ورشة الإكسيل ([11 مايو]) ✅

        محتاج تحويل **1000ج** جدية حجز:

        🟢 انستا باي: 100057017249
        🟢 فودافون كاش: 01002180432
        🟢 تحويل بنكي: CIB - حساب 100057017249

        أنهي طريقة دفع تناسبك؟ متى تـ توقع تـ حوّل؟

        ⚠️ تذكير: لازم لابتوب شخصي (تطبيق طول الـ 12 ساعة).
        ```

    === "📞 Call"

        ```
        "[الاسم] — متفقين على حجز ورشة الإكسيل. السعر 2000ج، 50% جدية + 50% أول محاضرة.

        أنهي طريقة دفع تـ فضلها؟ وعندك لابتوب جاهز؟"
        ```

??? danger "Stage 3: جاهز للتحويل 💳 (🔥 Hot)"

    ## السياق
    سأل عن الدفع وما رجعش.

    === "📱 WhatsApp"

        ```
        [الاسم] أهلاً 👋

        شفت إنك سألت قبل كده على طريقة الدفع لورشة الإكسيل.

        في حاجة عمالة تأخر؟

        السعر 2000ج فقط (الأرخص). جدية الحجز 1000ج بس.

        🟢 انستا باي: 100057017249
        🟢 فودافون كاش: 01002180432

        أنهي يـ ناسبك؟
        ```

    === "📞 Call"

        ```
        "[الاسم] — كلمتك أتأكد إن في حاجة محتاج توضيح. السعر 2000ج، جدية 1000ج. أنهي طريقة دفع أحسن ليك؟"
        ```

??? warning "Stage 4: مهتم - لم يتقدم (🟡 Warm)"

    ## السياق
    شاف السعر، قال "تمام"، ما تحرّكش. الـ objection غالباً: "وقتي ضيق" أو "أنا عارف Excel".

    ## الهدف
    كشف real objection + ربط بـ ROI زمني

    === "📱 WhatsApp"

        ```
        [الاسم] أهلاً 👋

        عرفت السعر لورشة الإكسيل (2000ج) وقلت "تمام". مع السعر ده، الـ objection غالباً مش فلوس.

        خليني أفهم:

        A) "وقتي ضيق" — 4 محاضرات في شهر، ساعتين بـ نص كل مرة
        B) "أنا عارف Excel كافي" — اعمل اختبار سريع
        C) "بـ فكر في وقت تاني" — احطك في list

        أيهم؟
        ```

        #### Follow-up (لو "B — أنا عارف Excel")
        ```
        تمام، 5 أسئلة سريعة. جاوب نعم/لأ:

        1. تعرف XLOOKUP والفرق بينه وبين VLOOKUP في return للـ array كاملة؟
        2. تـ ستخدم AVERAGEIFS وCOUNTIFS مع شروط متعددة + wildcards؟
        3. تعرف دوال الـ Array الجديدة (UNIQUE, FILTER, SEQUENCE, TRANSPOSE)؟
        4. تـ بني Dashboard كاملة بـ Pivot Charts + شرائح + Conditional Formatting؟
        5. تـ ستخدم Goal Seek أو Solver في scenarios مالية؟
        6. تعرف تـ شغّل AI داخل Excel نفسه؟

        قاعدة: 80% من اللي بـ يـ قولوا "أنا عارف Excel" بـ يـ قولوا "لأ" على 3+ أسئلة من دول.

        فين أنت؟
        ```

        #### Follow-up (لو "A — وقتي ضيق")
        ```
        12 ساعة في شهر = 3 ساعات/أسبوع. مش كتير لـ skill بـ تـ رجع لك 5+ ساعات أسبوعياً (lifetime).

        ROI مباشر:
        - الورشة: 12 ساعة استثمار + 2000ج
        - بعد الورشة: 5+ ساعات/أسبوع توفير في تقاريرك
        - Break-even: 2-3 أسابيع

        تـ كسب 100+ ساعة في السنة الأولى لوحدها. ينفع كده؟
        ```

    === "📞 Call"

        ```
        "[الاسم] — عرفت السعر وقلت 'تمام'. مع 2000ج، الـ objection مش فلوس.

        ايه اللي مخليك متردد بصراحة؟ 'وقت'؟ 'مستوايا كافي'؟ 'بـ فكر'؟

        [Branch — كل واحد رد مفصّل]"
        ```

??? warning "Stage 5: شاف السعر ولم يحجز (🟡 Warm)"

    ## السياق
    قال "هـ فكر" بعد التفاصيل.

    ## الهدف
    كسر الـ تسويف + commitment

    === "📱 WhatsApp"

        ```
        [الاسم] أهلاً 👋

        من 3 أيام، عرفت تفاصيل ورشة الإكسيل وقلت "هـ فكر".

        كلمة واحدة بـ تـ ساعدني:

        1️⃣ "هـ فكر هـ حجز قريب"
        2️⃣ "هـ فكر هـ حضر cheaper option (Udemy)"
        3️⃣ "هـ فكر مش الوقت المناسب"
        4️⃣ "هـ فكر مش هـ حجز"
        ```

    === "📞 Call"

        ```
        "[الاسم] — قلت 'هـ فكر'. سؤال مباشر: لو ضمنّالك إنك في 4 أسابيع هـ تـ ختصر تقاريرك الشهرية بـ 50%، هـ تـ حجز دلوقتي؟"
        ```

??? info "Stage 6: مرحلة الاستكشاف (🔵 Cold)"

    ## السياق
    لسه بـ يـ ستكشف.

    ## الهدف
    Discovery + ربط بـ pain شغلي + tie-in بـ محتوى الورشة

    === "📱 WhatsApp"

        ```
        [الاسم] أهلاً 👋

        شفت إنك بـ تـ سأل عن الإكسيل.

        خليني أسألك:

        أنت بـ تـ ستخدم Excel في شغلك يومياً؟ أصعب جزء بـ يـ ستهلك وقتك ايه؟

        - تقارير شهرية يدوية بـ تـ تكرر؟
        - مطابقات وlookups معقدة؟
        - Pivot من sources متعددة؟
        - Dashboards للمدير؟

        لما أعرف أصعب جزء، هـ قولك بالظبط المحاضرة اللي بـ تـ حله.
        ```

        #### Follow-up (بعد رد العميل)
        ```
        تمام. الورشة 4 محاضرات × 3 ساعات مع أ/ مصطفى القصاص، وكل محاضرة بـ تـ حل problem محدد لمحاسب شغّال:

        🔹 محاضرة 1: المعادلات الحسابية والإحصائية (AVERAGEIFS, COUNTIFS مع شروط متعددة) + التقريب الصحيح
        🔹 محاضرة 2: VLOOKUP، XLOOKUP، النصوص (PROPER + التنسيق)، التاريخ (NETWORKDAYS, MONTH)
        🔹 محاضرة 3: دوال الـ Array (UNIQUE, FILTER, SEQUENCE, TRANSPOSE) + Pivot Tables + Data Validation + Conditional Formatting
        🔹 محاضرة 4: Dashboards كاملة + Pivot Charts + شرائح + Goal Seek + Solver + AI integration + حماية الملفات

        أنت شغال في Excel، يعني الورشة بـ تـ علمك الـ shortcuts والـ advanced functions اللي بـ تـ وفر ساعات يومياً.

        السعر 2000ج. لازم لابتوب. تـ حب أحجزلك؟
        ```

    === "📞 Call"

        ```
        "[الاسم] — كنت بـ تـ سأل عن الإكسيل. ناخد 7 دقايق نفهم وضعك؟

        1. شغل Excel يومي؟
        2. ايه أصعب tasks بـ تـ آخد منك وقت؟
        3. حاولت تـ تعلم لوحدك (يوتيوب)؟
        4. عملت ROI على وقتك؟

        [Pitch بـ tie-in:]
        'الورشة 4 محاضرات × 3 ساعات مع أ/ مصطفى القصاص. كل محاضرة بـ تـ حل problem لمحاسب شغّال:

        المحاضرة الأولى: الدوال الإحصائية والحسابية اللي بـ تـ ختصر vlookups وlookups معقدة
        المحاضرة الثانية: XLOOKUP + النصوص + التاريخ
        المحاضرة الثالثة: Pivot Tables متقدمة + دوال الـ Array + Data Validation
        المحاضرة الرابعة: Dashboards + Goal Seek + Solver + AI داخل Excel

        السعر 2000ج. لازم لابتوب.'"
        ```

??? info "Stage 7: رفض (🔵 Cold)"

    === "📱 WhatsApp"

        ```
        [الاسم] أهلاً 👋

        شفت إنك قلت إن الورشة مش مناسبة. احترم.

        سؤال محايد: لو قعدت 4 ساعات الأسبوع الجاي على تقرير ممكن يـ خلص في 30 دقيقة، هـ تـ فكر تاني؟

        لو نعم → هـ حطك في list.
        لو لأ → كل التوفيق.
        ```

    === "📞 Call"

        ```
        "[الاسم] — مش هـ حاول أقنعك. كل التوفيق ليك.

        لو في 6 شهور قررت توفر وقتك في شغلك، كلمني. سلام."
        ```

## ❌ Anti-patterns لـ Angle 2

| ❌ | ✅ |
|----|----|
| pitch generic | اربط بـ pain زمني (ساعات بـ تـ ضيع) |
| تجاهل Udemy | اعترف + اشرح Live |
| تنسى لابتوب reminder | ذكّر صراحة |
| pitch "Excel كله" | حدد الـ functions اللي هـ تـ حل pain العميل |

| حالة الـ brief | الحرارة | الـ Stage | خطوتك |
|---|---|---|---|
| "تم التحويل ✅💰" | 🔥 | Stage 1 | تأكيد + ترحيب احترافي + ذكّره يـ جيب اللابتوب + تقارير من شغله |
| "تم الحجز ✅" | 🔥 | Stage 2 | timeline للتحويل + سهّل الدفع + تذكير اللابتوب |
