# 🎯 Angle 3: صاحب شركة عاوز يفهم تقاريره

> **الجمهور:** صاحب شركة (صغيرة-متوسطة). بيستلم Excel reports من محاسبه. الـ skills في Excel basic — مش بيقدر يـ verify.
> **الـ Pain:** "محاسبي بيوديني Excel sheet مش فاهم نصها. مش عارف لو الأرقام صح ولا فيه أخطاء."
> **الـ Hook:** "12 ساعة بتخليك تـ verify أي Excel report بتيجيلك + تتأكد إن محاسبك بيشتغل صح"

---

## 📋 بطاقة مرجعية سريعة

| العنصر | المحتوى |
|--------|---------|
| **اسم الورشة** | الإكسيل |
| **المحاضر** | أ/ مصطفى القصاص |
| **المدة** | 4 محاضرات × 3 ساعات |
| **السعر** | 4000ج → **2000ج** |
| **الـ Pain** | "بستلم Excel reports وما بفهمش" |
| **الـ Promise** | "تـ verify + تفهم + تكتشف الأخطاء" |

---

## 📚 الـ 7 Stages

??? danger "Stage 1: تم التحويل ✅💰 (🔥 Hot)"

    ## السياق
    صاحب الشركة حوّل. السيلز يأكد + يذكّر باللابتوب + reports.

    === "📱 WhatsApp"

        ```
        ✅ التحويل وصل، شكراً [الاسم]!

        🎉 مبروك! حجزك في ورشة الإكسيل مع أ/ مصطفى القصاص مؤكد.

        📋 التفاصيل:
        🔹 التاريخ: 11 مايو 2026
        🔹 المواعيد: الاثنين + الخميس، 6م-9م
        🔹 العنوان: 29 أ امتداد رمسيس، نقابة التجاريين، الدور 8

        ⚠️ **جيب اللابتوب** + **آخر تقارير Excel** من شركتك (مع إخفاء الـ data الحساسة).
        أ/ مصطفى هيوريك إزاي تـ verify كل number في تقاريرك بدقة.

        أهلاً بيك! 🌟
        ```

    === "📞 Call"

        ```
        "[الاسم] — مبروك. كصاحب شركة، الـ ROI من الورشة دي مختلف.

        نصيحة: جيب آخر Excel report من محاسبك (مع إخفاء الأرقام الحساسة). أ/ مصطفى هيوريك إزاي تكتشف لو فيه أخطاء أو inconsistencies.

        التاريخ والمواعيد: [التفاصيل]. عندك لابتوب؟"
        ```

??? danger "Stage 2: تم الحجز ✅ (🔥 Hot)"

    ## السياق
    اتفق على الحجز، لسه ما حوّلش.

    === "📱 WhatsApp"

        ```
        [الاسم] — متفقين على حجز ورشة الإكسيل ([11 مايو]) ✅

        محتاج تحويل **1000ج** جدية حجز.

        تخصمها كمصاريف training للشركة.

        🟢 انستا باي: 100057017249
        🟢 فودافون كاش: 01002180432
        🟢 تحويل بنكي: CIB - حساب 100057017249

        أنهي طريقة دفع تناسبك؟
        ```

    === "📞 Call"

        ```
        "[الاسم] — متفقين على الحجز. 2000ج، نص جدية + نص أول محاضرة. تقدر تخصمها كمصاريف. أنهي طريقة دفع أحسن ليك؟"
        ```

??? danger "Stage 3: جاهز للتحويل 💳 (🔥 Hot)"

    === "📱 WhatsApp"

        ```
        [الاسم] أهلاً 👋

        شفت إنك سألت قبل كده على طريقة الدفع لورشة الإكسيل.

        في حاجة عمالة تأخر؟ (مشغول؟ ظرف طارئ؟)

        🟢 انستا باي: 100057017249
        🟢 فودافون كاش: 01002180432

        أنهي يناسبك؟
        ```

    === "📞 Call"

        ```
        "[الاسم] — كلمتك أتأكد إن في حاجة محتاج توضيح. السعر 2000ج، جدية 1000ج."
        ```

??? warning "Stage 4: مهتم - لم يتقدم (🟡 Warm)"

    ## السياق
    شاف السعر، قال "تمام"، ما تحرّكش. الـ objection: "أنا مش محاسب، Excel مش مهم لي".

    ## الهدف
    اشرح الـ Excel value من زاوية صاحب الشركة (verification, decisions)

    === "📱 WhatsApp"

        ```
        [الاسم] أهلاً 👋

        عرفت السعر لورشة الإكسيل (2000ج) وقلت "تمام". كصاحب شركة، سؤال صريح:

        A) "أنا مش محاسب — Excel مش مهم"
        B) "محاسبي بيعمل ده"
        C) "وقتي ضيق"
        D) حاجة تانية

        أيهم؟
        ```

        #### Follow-up (لو "A — أنا مش محاسب")
        ```
        Excel **مش tool محاسبة بس** — هو tool القرارات.

        كصاحب شركة، Excel بيخليك:
        - تـ verify أي report بيوصلك
        - تعمل scenarios (لو زودت السعر 10%، إيه يحصل؟)
        - تحلل المبيعات بنفسك بـ Pivot في دقائق
        - تكتشف pattern قبل ما محاسبك يقولك

        ده مش "مهارة محاسبة" — ده "مهارة صاحب شركة".
        ```

        #### Follow-up (لو "B — محاسبي بيعمل ده")
        ```
        سؤال صريح:

        - في كم خطأ في Excel report بيوصلك سنوياً؟
        - تعرف لو محاسبك بيعمل Pivot صح؟
        - لو محاسبك سرقك بـ formula في Excel، هتكتشف؟

        الورشة مش بدل محاسبك — هي verification ليه.
        ```

    === "📞 Call"

        ```
        "[الاسم] — عرفت السعر وقلت 'تمام'. كلمتك نفهم.

        سؤال صريح: 'أنا مش محاسب' ولا 'محاسبي بيعمل ده'؟

        [Branch — كل واحد رد مفصّل]"
        ```

??? warning "Stage 5: شاف السعر ولم يحجز (🟡 Warm)"

    === "📱 WhatsApp"

        ```
        [الاسم] أهلاً —

        من 3 أيام، عرفت تفاصيل ورشة الإكسيل. وقلت "هفكر".

        1️⃣ "هفكر هحجز قريب"
        2️⃣ "هفكر هحجز محاسبي بدلي"
        3️⃣ "هفكر مش هحجز"

        كلمة واحدة.
        ```

        #### Follow-up (لو "2 — محاسبي بدلي")
        ```
        خيار وجيه. بس:

        - لو محاسبك بيتطور = ممكن ينقل من عندك بعد سنة
        - لو أنت بتتعلم = الـ knowledge بيفضل معاك

        أحسن: اتنينكم. الورشة 2000ج بس، خصم Multi-booking 4000ج للاتنين.
        ```

    === "📞 Call"

        ```
        "[الاسم] — قلت 'هفكر'. ناخد 5 دقايق؟

        سؤال: في آخر سنة، كم قرار مالي اتخذت بناءً على Excel report بدون verification؟

        [Branch]"
        ```

??? info "Stage 6: مرحلة الاستكشاف (🔵 Cold)"

    === "📱 WhatsApp"

        ```
        [الاسم] أهلاً —

        شفت إنك بتسأل عن الإكسيل.

        سؤال:

        أنت بتسأل لنفسك (صاحب شركة) ولا للموظف بتاعك (محاسب)؟

        (الـ approach مختلف)
        ```

    === "📞 Call"

        ```
        "[الاسم] — كنت بتسأل عن الإكسيل. ناخد 10 دقايق؟

        1. شركتك في إيه؟
        2. عندك محاسب داخلي؟
        3. آخر مرة فهمت Excel report لشركتك امتى؟
        4. ايه أكبر سؤال مش محاسبك جاوبه ليك؟"
        ```

??? info "Stage 7: رفض (🔵 Cold)"

    === "📱 WhatsApp"

        ```
        [الاسم] — احترم قرارك.

        سؤال محايد: لو في 6 شهور كانت غلطة Excel كلفت شركتك (ولو 10K)، هتفكر تاني؟

        لو نعم → احطك في list.
        لو لأ → كل التوفيق.
        ```

    === "📞 Call"

        ```
        "[الاسم] — مش هحاول أقنعك. سلام عليكم.

        لو في وقت قررت تطور قدرتك على verification، كلمني."
        ```

---

## ❌ Anti-patterns لـ Angle 3

| ❌ | ✅ |
|----|----|
| تكلمه كـ محاسب | كلمه كصاحب أعمال — لغة decisions |
| pitch "هتشتغل Excel pro" | "هتـ verify + تكتشف أخطاء" |
| تقلل من محاسبه | اعترف + اشرح verification |

---

## 🚦 شجرة القرار السريعة

```
صاحب شركة يجي من AI Agent
    ↓
Stages 1-3 → Closing سريع + tax-deductible reminder
Stage 4 → Top objection: "أنا مش محاسب" → reframe Excel كـ tool القرار
Stage 5 → غالباً يستثمر في موظف — اقترح الاتنين بـ Multi-booking
Stage 6 → Discovery يركز على Excel reports اللي بيستلمها
Stage 7 → reactivation بـ "غلطة Excel ممكن تكلفك" framing
```
