# 📓 ورشة هندسة التكاليف — Sales Playbook

> **المحاضر:** أ/ أحمد عاشور
> **المدة:** 8 محاضرات حضوري / 5 أونلاين × 3 ساعات
> **الجمهور:** محاسبين/مصانع/مقاولات + أصحاب أنشطة إنتاجية
> **اللي يميزها:** منظور إداري ومالي للتكاليف — مش بس قيود، بل تسعير + رقابة + اتخاذ قرار

---

## 📝 ملخص الورشة

### الـ Hook المركزي
> "تتحول من 'محاسب بيسجّل تكاليف' لـ 'مهندس تكاليف بيتخذ قرارات'"

### Differentiators
1. **منظور إداري** — مش بس قيود، التكلفة كأداة قرار
2. **تطبيق على المخزون + الإيرادات + التكاليف** — كل عناصر الشركة
3. **التسعير الصح** لكل منتج/خدمة
4. **المحاضر شغّال CFO** — أ/ أحمد عاشور
