# 🎯 Angle 3: صاحب نشاط إنتاجي

> **الجمهور:** صاحب مصنع/مشروع إنتاجي. مش عارف تكلفة منتجاته الفعلية. بيسعّر بالحدس.
> **الـ Pain:** "بسعّر منتجاتي بس مش متأكد لو فعلاً بربح. أحياناً بكتشف إن منتج كنت بحبه = بخسر فيه."
> **الـ Hook:** "تعرف تكلفة كل منتج بدقة + تسعّره صح = الفرق بين شركة بتربح وشركة بتخسر بدون ما تعرف"

---

## 📋 Quick Reference

| العنصر | المحتوى |
|--------|---------|
| **اسم الورشة** | هندسة التكاليف |
| **المحاضر** | أ/ أحمد عاشور |
| **المدة** | 8 محاضرات حضوري / 5 أونلاين × 3 ساعات |
| **الـ Pain** | "بسعّر بالحدس + مش عارف تكلفتي الفعلية" |
| **الـ Promise** | "تتحكم في تكاليف شركتك بدلاً من اللعب الأعمى" |
| **Top 3 Objections** | (1) "أنا مش محاسب" (2) "محاسبي بيعمل ده" (3) الوقت |

=== "Stage 4: مهتم - لم يتقدم (🟡 Warm)"

    === "📱 WhatsApp"

        ```
        [الاسم] أهلاً 👋

        عرفت السعر لورشة هندسة التكاليف وقلت "تمام". كصاحب نشاط، سؤال صريح:

        A) "أنا مش محاسب — الورشة عميقة"
        B) "محاسبي بيعمل ده بالفعل"
        C) "وقتي مش يسمح بـ 24 ساعة"
        D) "السعر"

        أيهم؟
        ```

        #### Follow-up (لو "B — محاسبي بيعمل ده")
        ```
        سؤال صريح:

        محاسبك بيقولك تكلفة كل منتج بالظبط؟ ولا بيقولك "إجمالي التكاليف"؟

        في 80% من المصانع المصرية، المحاسب بيحسب التكاليف الإجمالية، مش لكل منتج. ده معناه:
        - ممكن منتج تربح فيه 50% — بس مش هتعرف
        - ممكن منتج تخسر فيه 30% — وبتفضل تنتجه

        الورشة بتديك القدرة تـ verify دقة محاسبك + تحدد تكلفة كل منتج.

        سؤال: لو اكتشفت إن منتج واحد بتخسر فيه = خسارة كم في السنة؟
        ```

        #### Follow-up (لو "A — مش محاسب")
        ```
        الورشة بتفترض base محاسبي بسيط. صاحب الشركة اللي حضر قبل كده، عمل واحد من 2:
        1. حضر ورشة المحاسب المالي قبلها (للأساسيات)
        2. حضر هندسة التكاليف مع محاسبه

        اقتراحي: اعمل كول 5 دقايق نقرّر مع بعض أنسب طريق ليك. ممكن تبدأ بالمحاسب المالي + هندسة التكاليف لاحقاً.
        ```

## ❌ Anti-patterns لـ Angle 3

| ❌ ما تعملش | ✅ بدلها |
|-------------|---------|
| تكلمه كأنه محاسب | كلمه كصاحب أعمال — لغة ربح/خسارة |
| pitch "هتشتغل cost engineer" | "هتفهم تكلفتك + تسعّر صح" |
| تقلل من محاسبه | اعترف + اشرح gap الـ "تكلفة المنتج الفردي" |
| تقدم محتوى تقني | اشرح بأمثلة منتجات + قرارات |
