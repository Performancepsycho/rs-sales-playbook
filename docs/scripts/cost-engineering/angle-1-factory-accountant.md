# 🎯 Angle 1: محاسب في مصنع/مقاولات

> **الجمهور:** محاسب شغّال 2-7 سنين في مصنع أو شركة مقاولات. بيتعامل مع تكاليف يومياً بس بشكل سطحي.
> **الـ Pain:** "بسجل تكاليف الإنتاج بس مش فاهم لو فيه انحرافات أو ليه التكلفة بتعلى. مديري بيسأل وأنا أرد بـ generic."
> **الـ Hook:** "تتحول من 'مسجّل تكاليف' لـ 'محلل تكاليف' — تجاوب أسئلة مديرك بـ datapoint مش guess"

---

## 📋 Quick Reference

| العنصر | المحتوى |
|--------|---------|
| **اسم الورشة** | هندسة التكاليف |
| **المحاضر** | أ/ أحمد عاشور |
| **المدة** | 8 محاضرات حضوري / 5 أونلاين × 3 ساعات |
| **الـ Pain** | "بسجل تكاليف بدون فهم — مش قادر أحلل أو أتخذ قرار" |
| **الـ Promise** | "تطلع محلل تكاليف يقدر يجاوب أسئلة الإدارة" |
| **Top 3 Objections** | (1) "متخصصة جداً — هل ينفع لي؟" (2) السعر (3) الوقت |

---

## 📚 الـ 7 Stages

!!! tip "كيف تستخدم الـ Tabs"
    اضغط على Stage اللي تحتاجه. داخل كل Stage هتلاقي tab WhatsApp + tab Call.

=== "Stage 1: تم التحويل ✅💰 (🔥 Hot)"

    ### 📱 WhatsApp
    ```
    ✅ التحويل وصل، شكراً [الاسم]!

    🎉 مبروك! حجزك في ورشة هندسة التكاليف مع أ/ أحمد عاشور مؤكد.

    ده القرار اللي هيخرجك من الـ data entry لمستوى محلل تكاليف — مديرك هيلاحظ الفرق في أول شهر.

    📋 التفاصيل:
    [نفس template]

    نصيحة: جيب معاك آخر تقرير تكاليف عملته — هنشوف فيه فرص للتحسين.

    أهلاً بيك! 🌟
    ```

=== "Stage 2: تم الحجز ✅ (🔥 Hot)"

    ### 📱 WhatsApp
    ```
    [الاسم] — متفقين على حجز ورشة هندسة التكاليف ([التاريخ]) ✅

    محتاج تحويل 1750ج جدية حجز:
    [طرق الدفع]
    ```

=== "Stage 3: جاهز للتحويل 💳 (🔥 Hot)"

    ### 📱 WhatsApp
    ```
    [الاسم] — شفت إنك سألت قبل كده على طريقة الدفع لورشة هندسة التكاليف.

    في حاجة عمالة تأخر؟
    [طرق الدفع]
    ```

=== "Stage 4: مهتم - لم يتقدم (🟡 Warm)"

    ### 📱 WhatsApp — الـ Opener
    ```
    [الاسم] أهلاً 👋

    [اسم السيلز] من فريق RS.

    عرفت السعر لورشة هندسة التكاليف وقلت "تمام". سؤال صريح:

    A) "هل دي متخصصة جداً عليّ؟" (مش متأكد لو الورشة fit)
    B) "السعر — مش متأكد من الـ ROI"
    C) "الوقت — شغّال + الورشة 24 ساعة"
    D) "هل التكاليف فعلاً ينفع تخصص؟"

    أيهم؟
    ```

    #### Follow-up (لو "A — متخصصة جداً")
    ```
    سؤال محترم.

    الورشة مش بس "محاسبة تكاليف". هي "هندسة تكاليف" — يعني استخدام الأرقام في:
    ✅ التسعير الصح للمنتجات
    ✅ الرقابة على المخزون والانحرافات
    ✅ اتخاذ قرارات (بيع/إيقاف نشاط، توسع، إلخ)

    شغّال في مصنع أو مقاولات؟ هي بالظبط ليك. شغّال في شركة خدمات؟ هي مفيدة برضو لكن في الـ pricing.

    لو محتاج نتأكد إنها fit ليك تحديداً، اعمل كول 5 دقايق وأنا أوضح بناءً على شغلك.
    ```

    #### Follow-up (لو "D — هل التكاليف ينفع تخصص؟")
    ```
    سؤال ذكي.

    السوق المصري:
    - محاسب تكاليف junior (2-3 سنين خبرة): 8,000-12,000ج
    - محاسب تكاليف senior (5+ سنين): 15,000-25,000ج
    - مدير تكاليف: 30,000+ج

    التكاليف من أعلى التخصصات أجراً في المحاسبة (بعد CFO و الضرايب). ليه؟ لأن الشركات الإنتاجية بتعتمد عليها بالكامل لقرارات التسعير + التوسع.

    شركتك إنتاجية؟ يبقى التخصص ده = ترقية حتمية في 1-2 سنة.
    ```

    ### 📞 Call
    ```
    "[الاسم] — عرفت السعر لهندسة التكاليف وقلت 'تمام'. كلمتك نفهم.

    سؤال صريح: 'متخصصة عليك'؟ السعر؟ الوقت؟ ولا 'هل تنفع تخصص'؟

    [Branch]"
    ```

=== "Stage 5: شاف السعر ولم يحجز (🟡 Warm)"

    ### 📱 WhatsApp — الـ Opener
    ```
    [الاسم] أهلاً 👋

    من 3 أيام، عرفت تفاصيل ورشة هندسة التكاليف. وقلت "هفكر".

    سؤال محدد:

    1️⃣ "هفكر هحجز قريب"
    2️⃣ "هحجز بعد ما الشركة تدعم"
    3️⃣ "هفكر مش الورشة المناسبة"
    4️⃣ "هفكر مش هحجز"

    كلمة واحدة.
    ```

    ### 📞 Call
    ```
    "[الاسم] — عرفت تفاصيل هندسة التكاليف وقلت 'هفكر'. ناخد 5 دقايق؟

    سؤال: لو ضمنّالك إن في 6 شهور هتقدر تجاوب أي سؤال تكاليفي بـ datapoint، هتحضر دلوقتي؟

    [Branch]"
    ```

=== "Stage 6: مرحلة الاستكشاف (🔵 Cold)"

    ### 📱 WhatsApp — الـ Opener
    ```
    [الاسم] أهلاً 👋

    شفت إنك بتسأل عن ورشة هندسة التكاليف.

    سؤال قبل ما أبعتلك التفاصيل:

    أنت شغّال في إيه نوع شركة؟ مصنع؟ مقاولات؟ خدمات؟ تجارية؟

    عشان الورشة بنركز فيها على المصانع والمقاولات أكتر — لو خدمات، عندنا approach مختلف.
    ```

    ### 📞 Call
    ```
    "[الاسم] — كنت بتسأل عن هندسة التكاليف. ناخد 10 دقايق نفهم وضعك؟

    Discovery:
    1. شغّال في إيه نوع شركة؟ بقالك قد إيه؟
    2. ايه طبيعة شغلك مع التكاليف يومياً؟
    3. ايه أصعب سؤال تكاليفي بيتسأل لك في الشغل؟
    4. شركتك بتاخد قرارات إنتاج/تسعير بناءً على إيه؟

    [Pitch]"
    ```

    ```
    ايه السبب الحقيقي؟

    [Goodwill close]"
    ```

## ❌ Anti-patterns لـ Angle 1

| ❌ ما تعملش | ✅ بدلها |
|-------------|---------|
| تقدم الورشة كـ "محاسبة تكاليف" generic | "هندسة تكاليف" = اتخاذ قرار |
| pitch لمحاسب خدمات | لو خدمات، اقترح ورشة تانية |
| تتجاهل الـ context (مصنع vs مقاولات) | اسأل عن النشاط + خصص |

## 🚦 Quick Decision Tree

```
محاسب في مصنع/مقاولات يجي من AI Agent
    ↓
Stage 1-3 → Closing سريع
Stage 4 → Top objection: "متخصصة جداً عليّ"
Stage 5 → urgency play بـ ترقية متوقعة
Stage 6 → Discovery يركز على نوع الشركة + الـ pain
Stage 7 → reactivation أو suggest ورشة تانية
```
