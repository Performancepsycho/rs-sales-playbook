# 📙 ورشة Odoo Accounting — Sales Playbook

> **المحاضر:** أ/ إسلام سعيد
> **المدة:** 8 محاضرات × 3 ساعات = 24 ساعة تدريبية
> **الجمهور:** كل المستويات + أصحاب شركات
> **اللي يميزها:** ERP عملي على Odoo (مبيعات + مشتريات + مخازن + حسابات عامة)
> **⚠️ ملحوظة:** يشترط إحضار اللابتوب الخاص بالمتدرب (للحضوري)

---

## 📝 ملخص الورشة

### الـ Hook المركزي
> "تتعلم Odoo اللي السوق المصري بيتطلبه دلوقتي — وتشتغل بمستوى محاسب ERP مش محاسب تقليدي"

### Differentiators
1. **عملي 100%** — هتشتغل على نظام Odoo فعلي طول الورشة
2. **شامل دورات الشغل** — مبيعات + مشتريات + مخازن + حسابات عامة
3. **المحاضر متخصص في Odoo** — أ/ إسلام سعيد
4. **تطبيق على بيانات شركات حقيقية**
