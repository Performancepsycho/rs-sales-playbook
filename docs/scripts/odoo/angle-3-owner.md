# 🎯 Angle 3: صاحب شركة يبغى implement Odoo

> **الجمهور:** صاحب شركة (صغيرة-متوسطة). سامع عن ERP. عاوز يفهم Odoo قبل ما يقرر يطبقه.
> **الـ Pain:** "كل اللي حواليا بيقولوا 'لازم تطبق Odoo'. أنا مش عارف إيه فايدته فعلاً ولا إيه التكلفة الحقيقية."
> **الـ Hook:** "تفهم Odoo بنفسك قبل ما تدفع لشركة implementation = ما حدش يقدر يضحك عليك"

---

## 📋 Quick Reference

| العنصر | المحتوى |
|--------|---------|
| **اسم الورشة** | Odoo Accounting |
| **المحاضر** | أ/ إسلام سعيد |
| **المدة** | 8 محاضرات × 3 ساعات (24 ساعة) |
| **⚠️ متطلب** | اللابتوب الشخصي |
| **الـ Pain** | "عاوز أفهم Odoo قبل ما أقرر أطبقه في شركتي" |
| **الـ Promise** | "تتفاوض مع شركات الـ implementation من موقع قوة + تختار صح" |
| **Top 3 Objections** | (1) "أنا مش محاسب" (2) "12 محاضرة كتير على شغلي" (3) "محاسبي/IT يقدروا يقرروا" |

# Stage 4: مهتم - لم يتقدم (🟡 Warm)

### 📱 WhatsApp — الـ Opener
```
[الاسم] أهلاً 👋

عرفت السعر لورشة Odoo وقلت "تمام". كصاحب شركة، سؤال صريح:

A) "أنا مش محاسب — الورشة عميقة عليّ؟"
B) "وقتي مش يسمح بـ 24 ساعة"
C) "محاسبي/IT يقدروا يحضروا بدلي"
D) "في شركة implementation بنشتغل معاها — مش محتاج"

أيهم؟
```

#### Follow-up (لو "C — موظفي يحضروا")
```
خيار وجيه. بس استني:

- موظفك يحضر = هو بيتطور (هيستفيد منها لو نقل من عندك)
- أنت تحضر = أنت تتحقق من شغل موظفك + بتتفاوض مع شركات implementation بـ knowledge

أحسن خيار: **اتنينكم**. تكلفة 2x، بس انت تحمي شركتك من القرارات الغلط في الـ implementation.

عاوز أبعتلك breakdown للـ ROI؟
```

#### Follow-up (لو "D — في شركة implementation")
```
سؤال صريح:

كم العرض من شركة الـ implementation؟ ولو هما يعملوا الشغل خطأ، انت هتعرف؟

الورشة بتديك:
✅ القدرة تـ verify الـ scope والتسعير
✅ تعرف الـ best practices (هتمنع mistakes كبيرة)
✅ تتفاوض من موقع قوة (هيوفرلك 20-50% من تكلفة الـ implementation)

غالباً الورشة بترجع تكلفتها في عرض واحد بس.
```

### 📞 Call
```
"[الاسم] — عرفت السعر لـ Odoo وقلت 'تمام'. كلمتك نفهم.

سؤال صريح كصاحب شركة: 'مش محاسب'؟ 'وقت'؟ 'موظفي يحضر'؟

[Branch]"
```

## ❌ Anti-patterns لـ Angle 3

| ❌ ما تعملش | ✅ بدلها |
