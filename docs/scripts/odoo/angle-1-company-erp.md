# 🎯 Angle 1: محاسب شركته بتنقل لـ ERP

> **الجمهور:** محاسب شغّال + الشركة قررت تطبّق Odoo (أو في عملية implementation)
> **الـ Pain:** "شركتنا بتنقل لـ Odoo، أنا تايه. خايف يلاقوني مش جاهز ويستبدلوني."
> **الـ Hook:** "تتقن Odoo قبل ما الشركة تخلص implementation = تبقى الـ go-to person في الفريق"

---

## 📋 Quick Reference

| العنصر | المحتوى |
|--------|---------|
| **اسم الورشة** | Odoo Accounting |
| **المحاضر** | أ/ إسلام سعيد |
| **المدة** | 8 محاضرات × 3 ساعات (24 ساعة) |
| **⚠️ متطلب** | اللابتوب الشخصي (للحضوري) |
| **الـ Pain** | "شركتي بتنقل لـ ERP وأنا مش جاهز" |
| **الـ Promise** | "تبقى الـ Odoo expert في فريقك = أمان وظيفي" |
| **Top 3 Objections** | (1) "هل ينفع أتعلم في الشغل؟" (2) السعر (3) "ميعاد الـ implementation عندنا قريب — خايف" |

## 📚 الـ 7 Stages

!!! tip "كيف تستخدم الـ Tabs"
    اضغط على Stage اللي تحتاجه. داخل كل Stage هتلاقي tab WhatsApp + tab Call.

=== "Stage 1: تم التحويل ✅💰 (🔥 Hot)"

    ### 📱 WhatsApp
    ```
    ✅ التحويل وصل، شكراً [الاسم]!

    🎉 مبروك! حجزك في ورشة Odoo Accounting مع أ/ إسلام سعيد مؤكد.

    ده decision زمني — كل أسبوع ENA تتعلم Odoo قبل ما الشركة تخلص implementation = ميزة أكبر بكتير.

    📋 التفاصيل:
    [نفس template]

    ⚠️ مهم: جيب اللابتوب معاك في كل محاضرة — هتشتغل live على Odoo.

    نصيحة: اعرف لو في إصدار Odoo معين شركتك بتطبقه (Community ولا Enterprise) — قول للمحاضر يركز عليه.

    أهلاً بيك! 🌟
    ```

=== "Stage 2: تم الحجز ✅ (🔥 Hot)"

    ### 📱 WhatsApp
    ```
    [الاسم] — متفقين على حجز ورشة Odoo ([التاريخ]) ✅

    محتاج تحويل 1500ج جدية حجز:
    [طرق الدفع]

    سؤال مهم: عندك لابتوب جاهز؟ (لازم في الحضوري). ولو عندك ضغط زمني (الـ implementation عندكم قريب)، قول وأرتبلك المجموعة الأقرب.
    ```

=== "Stage 3: جاهز للتحويل 💳 (🔥 Hot)"

    ### 📱 WhatsApp
    ```
    [الاسم] — شفت إنك سألت قبل كده على طريقة الدفع لـ Odoo.

    في حاجة عمالة تأخر؟ (خصوصاً مع ضغط الـ implementation عندكم؟)

    [طرق الدفع]
    ```

=== "Stage 4: مهتم - لم يتقدم (🟡 Warm)"

    ### 📱 WhatsApp — الـ Opener
    ```
    [الاسم] أهلاً 👋

    [اسم السيلز] من فريق RS.

    عرفت السعر لورشة Odoo وقلت "تمام". سؤال صريح:

    A) "هل ينفع أتعلم Odoo في الشغل بدون ورشة؟"
    B) "السعر — مش متأكد من الـ ROI"
    C) "الـ implementation عندنا قريب جداً — خايف الورشة تتأخر علي"
    D) حاجة تانية

    أيهم؟
    ```

    #### Follow-up (لو "A — هتعلم في الشغل")
    ```
    سؤال محترم.

    التعلم في الشغل ممكن، بس:
    - بياخد 6-12 شهر بدل شهرين
    - بتتعلم بـ trial & error (والأخطاء بتسجل)
    - بتعتمد على الـ implementation team — لما يمشوا، انت لوحدك

    الورشة بتديك:
    ✅ Foundation كامل في 24 ساعة
    ✅ تطبيق على Odoo فعلي (مش documentation)
    ✅ المحاضر متاح للأسئلة الـ ad-hoc

    سؤال: متى الـ implementation عندكم بيخلص؟ لو 3-6 شهور، الورشة هتنقذك.
    ```

    #### Follow-up (لو "C — Implementation قريب")
    ```
    ده exactly اللي عملنا الورشة عشانه.

    قبل الـ implementation أحسن من بعده. الورشة 8 محاضرات (شهرين) — لو سجلت في المجموعة الجاية، هتخلصها قبل ما الـ implementation يخلص.

    عندنا مجموعة جاية في [التاريخ]. لو عندك ضغط أكبر، عندنا مجموعة intensive (3 محاضرات في الأسبوع بدل واحدة) — بتخلص في 3 أسابيع.

    أنهي يناسب timeline شركتك؟
    ```

    ### 📞 Call
    ```
    "[الاسم] — عرفت السعر لـ Odoo وقلت 'تمام'. كلمتك نفهم.

    سؤال صريح: ضغط الـ implementation عندكم متى؟ ده هيحدد إذا كان الـ timing مهم.

    [Branch]"
    ```

=== "Stage 5: شاف السعر ولم يحجز (🟡 Warm)"

    ### 📱 WhatsApp — الـ Opener
    ```
    [الاسم] أهلاً 👋

    من 3 أيام، عرفت تفاصيل ورشة Odoo. وقلت "هفكر".

    سؤال محدد:

    1️⃣ "هفكر هحجز قريب"
    2️⃣ "هفكر هحجز بعد ما الشركة تدعم"
    3️⃣ "هفكر هتعلم في الشغل بدون ورشة"
    4️⃣ "هفكر مش هحجز"

    كلمة واحدة بتساعدني.
    ```

    ### 📞 Call
    ```
    "[الاسم] — عرفت تفاصيل Odoo وقلت 'هفكر'. ناخد 5 دقايق نحسم؟

    سؤال: متى الـ implementation عندكم بيخلص؟ ولو خلص بدون ما تكون expert، ايه الـ scenario؟

    [لو في pain حقيقي → اربط بقيمة الورشة]"
    ```

=== "Stage 6: مرحلة الاستكشاف (🔵 Cold)"

    ### 📱 WhatsApp — الـ Opener
    ```

    شفت إنك بتسأل عن ورشة Odoo.

    سؤال قبل ما أبعتلك التفاصيل:

    شركتك حالياً بتشتغل على Odoo؟ ولا بتفكروا تطبقوه؟ ولا أنت بتسأل لتطوير شخصي؟

    (الـ approach مختلف لكل واحد)
    ```

    ### 📞 Call
    ```
    "[الاسم] — كنت بتسأل عن Odoo. ناخد 10 دقايق نفهم وضعك؟

    Discovery:
    1. أنت محاسب شغّال؟ بقالك قد إيه؟
    2. شركتك بتشتغل Odoo حالياً؟ ولا بتفكروا؟ ولا أنت لتطوير شخصي؟
    3. ايه أكبر سؤال عندك في Odoo دلوقتي؟
    4. لو ما تعلمتش Odoo، إيه الـ scenario في الـ 6 شهور الجاية؟

    [Pitch focused on company-ERP angle]"
    ```

## ❌ Anti-patterns لـ Angle 1

| ❌ ما تعملش | ✅ بدلها |
|-------------|---------|
| pitch "هتشتغل ERP consultant" — هو شغّال أصلاً | "هتبقى Odoo expert في فريقك" |
| تتجاهل ضغط الـ implementation timeline | اسأل عن الـ deadline + اربط بالعجالة |
| تنسى الـ laptop requirement | ذكّر صراحة |
| تقلل من تجربة "التعلم في الشغل" | اعترف بصعوبتها + قدم الـ alternative |

```
محاسب شركته بتنقل لـ ERP يجي من AI Agent
    ↓

Stage 4 → Top objection: "هل ينفع أتعلم في الشغل؟"
Stage 5 → urgency play بـ implementation timeline
Stage 6 → Discovery يركز على company status + timeline
Stage 7 → reactivation أو suggest workshop آخر
```
