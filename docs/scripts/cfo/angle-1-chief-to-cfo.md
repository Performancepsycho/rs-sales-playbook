# 🎯 Angle 1: رئيس حسابات طموح للـ CFO

> **الجمهور:** رئيس حسابات شغّال 7+ سنين. شاطر في الـ accounting + reporting. عاوز ينقل لـ CFO أو financial director.
> **الـ Pain:** "أنا في سقف وظيفي. عاوز أنقل لـ CFO بس مفيش تأهيل واضح + الفرص محدودة."
> **الـ Hook:** "تخرج بـ tools + thinking الـ CFO الحقيقي = CFO ready في 8 محاضرات"

---

## 📋 Quick Reference

| العنصر | المحتوى |
|--------|---------|
| **اسم الورشة** | المدير المالي CFO |
| **المحاضر** | أ/ أحمد عاشور |
| **المدة** | متقدمة (يحدد الجدول) |
| **الـ Pain** | "في سقف وظيفي + عاوز أنقل لـ CFO" |
| **الـ Promise** | "CFO ready: tools + decisions + executive thinking" |
| **Top 3 Objections** | (1) السعر (الأعلى في الورش) (2) "هل ينفع بدون CFA؟" (3) "هل الفرص فعلاً موجودة؟" |

## 📚 الـ 7 Stages

!!! tip "كيف تستخدم الـ Tabs"
    اضغط على Stage اللي تحتاجه. داخل كل Stage هتلاقي tab WhatsApp + tab Call.

=== "Stage 1: تم التحويل ✅💰 (🔥 Hot)"

    ## السياق
    العميل **حوّل فلوس فعلاً**. الـ AI أكد التحويل. السيلز يأكد + يرحب + يجاوب على أسئلة محتملة قبل الموعد.

    ## الهدف
    1. تأكيد رسمي للحجز
    2. ترحيب احترافي يبني الـ trust
    3. تسليم كل التفاصيل (موعد، عنوان، جروب)
    4. **ما تـ pitchش الورشة تاني** — العميل دفع، خلاص

    === "📱 WhatsApp"

        ```
        ✅ التحويل وصل، شكراً [الاسم]!

        🎉 مبروك! حجزك في ورشة المدير المالي CFO مع أ/ أحمد عاشور مؤكد رسمياً.

        📋 التفاصيل:
        • الورشة: المدير المالي CFO
        • المحاضر: أ/ أحمد عاشور
        • التاريخ: [تاريخ بداية المجموعة]
        • المواعيد: [الأيام والوقت]
        • النوع: Online (Zoom — تفاعلي)

        💰 خطة الدفع:
        • المدفوع: 3000ج (50% جدية حجز) ✅
        • المتبقي: 3000ج في أول محاضرة (بدون فوايد)

        ⚠️ مهم ادخل الـ Zoom قبل الموعد بـ 10 دقايق + اتأكد من الميك والكاميرا. لينك Zoom + جروب الواتساب هيوصلك قبل المحاضرة الأولى بيوم.

        أهلاً بيك في عيلة RS! 🌟
        ```

    === "📞 Call"

        ```
        "السلام عليكم [الاسم]، معاك [اسم السيلز] من RS.

        شفت إن التحويل وصل — مبروك على الحجز! 🎉

        كلمتك بسرعة عشان أأكدلك التفاصيل صوتياً وأرد على أي سؤال محتمل قبل ما تيجي المحاضرة الأولى.

        عندك دقيقتين؟"
        ```

        #### Confirmation Talking Points (دقيقة 1-3)
        1. "أكد التاريخ والوقت — [التفاصيل] — مظبوط معاك؟"
        2. "تعرف العنوان؟ Online (Zoom — تفاعلي) — أبعتلك location على الواتساب لو مش متأكد"
        3. "هتلاقي أ/ أحمد عاشور في انتظارك — تقدر تسأل أي حاجة"
        4. "في أي سؤال محتاج توضيح قبل المحاضرة الأولى؟"

        #### Closing
        ```
        "خلاص [الاسم]، أنا هنا لو احتجت أي حاجة قبل أو بعد المحاضرة. شكراً ليك على ثقتك في RS — هتشوف بنفسك ليه 50,000 محاسب اختارونا من 2014. سلام عليكم."
        ```

    ### ❌ Anti-patterns Stage 1
    - تـ pitch الورشة تاني (العميل دفع، خلاص)
    - تسأل "ليه اخترتنا؟" — feedback time مش الآن
    - تأخر في إرسال التأكيد > 30 دقيقة من التحويل
    - تنسى تذكر العنوان والوقت بالظبط


=== "Stage 4: مهتم - لم يتقدم (🟡 Warm)"

    === "📱 WhatsApp"

        ```
        [الاسم] أهلاً 👋

        عرفت السعر لورشة المدير المالي CFO وقلت "تمام". سؤال صريح:

        A) "السعر عالي" (الورشة الأعلى)
        B) "هل ينفع بدون CFA؟"
        C) "هل فرص CFO فعلاً موجودة في السوق؟"
        D) "محتاج وقت أفكر"

        أيهم؟
        ```

        #### Follow-up (لو "A — السعر عالي")
        ```
        السعر فعلاً الأعلى في الأكاديمية. وفي سبب:

        - الورشة بتعلمك tools متقدمة (Power BI, DAX, Financial Modeling) = ساعات بناء عالية للمحاضر
        - المحاضر CFO شغّال — وقته بمئات الجنيهات/الساعة
        - المحتوى = الفرق بين 12,000ج/شهر (رئيس حسابات) و 40,000+ج/شهر (CFO)

        لو الورشة بتنقّلك لـ CFO في خلال سنة، الفرق بترجع تكلفة الورشة في شهر مرتب واحد.

        تقسيط 50/50 بدون فوايد + فيزا المشتريات. ينفع نتكلم 10 دقايق نظبط الأرقام؟
        ```

        #### Follow-up (لو "B — بدون CFA")
        ```
        سؤال ذكي.

        CFA = Designation عالمية (3-4 سنين دراسة). محترمة جداً.

        الورشة دي ≠ بديل CFA. هي **practical CFO toolkit** للسوق المصري:
        - Tools اللي بيتطلبها السوق المحلي (Power BI, Excel Advanced)
        - Thinking framework (decisions, budget rolling)
        - Local context (financial reporting standards, taxation effects)

        الـ CFA ينفع لما تشتغل في multinational. الورشة دي للسوق المصري الفعلي.

        أحسن combo: الورشة دلوقتي + CFA على المدى الطويل. مش "أو".
        ```

        #### Follow-up (لو "C — هل الفرص موجودة")
        ```
        داتا من السوق:
        - مصر فيها 10,000+ شركة متوسطة-كبيرة محتاجة CFOs
        - متوسط مرتب CFO: 30,000-100,000+ج
        - الـ supply محدود — مفيش CFOs مدربين كفاية
        - الـ growth path عادة: محاسب → senior → رئيس حسابات → CFO (15-20 سنة بدون تأهيل، 7-10 سنين معه)

        الفرص موجودة. التحدي: تكون جاهز لما تيجي.
        ```

## ❌ Anti-patterns لـ Angle 1

| ❌ ما تعملش | ✅ بدلها |
|-------------|---------|
| تكلمه كـ junior | احترم خبرته |
| تستهتر بـ CFA | اعترف + اشرح الـ complementary value |
| pitch generic عن "ترقية" | اربط بـ tools محددة (Power BI, Modeling) |
| تخصم بدون شرط | اعرض تقسيط، مش خصم |

## 🚦 Quick Decision Tree

```
رئيس حسابات → CFO يجي من AI Agent
    ↓
Stage 1-3 → Closing سريع
Stage 4 → Top objection: "السعر" أو "بدون CFA"
Stage 5 → غالباً بيقارن بـ CFA — اشرح الـ complementary
Stage 6 → Discovery يركز على gap الحالي + طموح
Stage 7 → reactivation محترم
```
