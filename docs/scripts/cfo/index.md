# 📒 ورشة المدير المالي CFO — Sales Playbook

> **المحاضر:** أ/ أحمد عاشور
> **المدة:** متقدمة
> **الجمهور:** رؤساء حسابات + مديرين ماليين + أصحاب شركات
> **اللي يميزها:** الورشة الأعلى مستوى — Financial Modeling + Power BI + قرارات استراتيجية

---

## 📝 ملخص الورشة

### الـ Hook المركزي
> "تخرج CFO جاهز — مش بس بـ knowledge، بل بـ tools (Power BI, Modeling) + decision-making framework"

### Differentiators
1. **Financial Modeling + What-If Analysis**
2. **Power BI + DAX + Pivot Tables (Advanced)**
3. **Budget Rolling + Forecasting**
4. **Dashboards interactive للـ executive presentations**
5. **المحاضر شغّال CFO فعلياً** — أ/ أحمد عاشور
