## 🎯 خصومات الـ Multi-Booking

> **متى تطبّق:** لو حد هيحجز **أكتر من ورشة**، أو **أكتر من عميل** بيحجزوا مع بعض.

=== "حساب الباقة"

    **مثال 1:** عميل واحد + ورشتين (مالي + ضرايب)
    - السعر العادي: 3250 + 5250 = **8500ج**
    - الـ Multi-booking: 3000 + 5000 = **8000ج**
    - **التوفير: 500ج**

    **مثال 2:** 3 عملاء (زمايل) + ورشة المحاسب المالي
    - السعر العادي: 3250 × 3 = **9750ج**
    - الـ Multi-booking: 3000 × 3 = **9000ج**
    - **التوفير: 750ج**

    **مثال 3:** عميل واحد + 3 ورش (مالي + ضرايب + تكاليف)
    - السعر العادي: 3250 + 5250 + 3500 = **12000ج**
    - الـ Multi-booking: 3000 + 5000 + 3200 = **11200ج**
    - **التوفير: 800ج**

=== "السعر الأقصى"

    لكل ورشة، السعر أدنى مسموح بيه (الـ multi-booking):

    | الورشة | السعر العادي | أدنى سعر |
    |--------|--------------|----------|
    | المحاسب المالي | 3250 | **3000** |
    | إعداد القوائم | 2500 | **2000** |
    | خبير الضرائب | 5250 | **5000** |
    | Odoo | 3000 | **3000** (= السعر العادي) |
    | هندسة التكاليف | 3500 | **3200** |
    | التحليل المالي | 5000 | **4000** |
    | المدير المالي | 6000 | **6000** (= السعر العادي) |

    !!! warning "ممنوع نزول تحت أدنى سعر"
        أدنى سعر مسموح بيه = الـ multi-booking. ممنوع النزول تحته بدون موافقة Director.

=== "كيف تعرضها"

    **❌ ما تقولش:** "هخصملك"
    **✅ قول:** "بما إنك بتحجز أكتر من ورشة، عندنا package pricing"

    **سكريبت WhatsApp:**
    ```
    [الاسم] —

    شفت إنك مهتم بـ [الورشة 1] + [الورشة 2].

    عندنا package pricing لما حد بياخد ورشتين أو أكتر:
    • [الورشة 1]: [السعر الجديد]ج (بدلاً من [السعر العادي]ج)
    • [الورشة 2]: [السعر الجديد]ج (بدلاً من [السعر العادي]ج)
    • **الإجمالي: [الإجمالي الجديد]ج**

    التوفير الإجمالي: [مبلغ التوفير]ج

    تحب نأكد الحجز؟
    ```

    **سكريبت Call:**
    > "[الاسم] — لاحظت إنك مهتم بأكتر من ورشة. عندنا سعر خاص للـ multi-booking. الـ [الورشة 1] بـ [السعر] بدلاً من [السعر العادي]، والـ [الورشة 2] بـ [السعر] بدلاً من [السعر العادي]. الإجمالي بيوفّرلك [التوفير]ج. ينفع كده؟"
