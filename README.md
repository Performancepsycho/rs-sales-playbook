## 📚 المحتوى

- **9 ورش × 3 angles × 7 stages ≈ 189 سكريبت** (واتساب + كول)
- **معالجة اعتراضات** بإطار A.C.R
- **إدارة الفريق** (KPIs, 1-on-1s)
- **تقارير قيادية** (يومي/أسبوعي/شهري)
- **تدريب** (role-play scenarios)
- **ربط الماركتينج** (lead handoff + feedback)

## 🛠️ كيف تـ build الـ site محلياً

```powershell
# تنصيب MkDocs Material
pip install mkdocs-material

# تشغيل local server
mkdocs serve

# build الـ site
mkdocs build

# Deploy على GitHub Pages
mkdocs gh-deploy
```
