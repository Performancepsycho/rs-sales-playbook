    🎯 خصومات الـ Multi-Booking¶

    متى تطبّق: لو حد هيحجز أكتر من ورشة، أو أكتر من عميل بيحجزوا مع بعض.

    مثال 1: عميل واحد + ورشتين (مالي + ضرايب) - السعر العادي: 3250 + 5250 = 8500ج - الـ Multi-booking: 3000 + 5000 = 8000ج - التوفير: 500ج

    مثال 2: 3 عملاء (زمايل) + ورشة المحاسب المالي - السعر العادي: 3250 × 3 = 9750ج - الـ Multi-booking: 3000 × 3 = 9000ج - التوفير: 750ج

    مثال 3: عميل واحد + 3 ورش (مالي + ضرايب + تكاليف) - السعر العادي: 3250 + 5250 + 3500 = 12000ج - الـ Multi-booking: 3000 + 5000 + 3200 = 11200ج - التوفير: 800ج

    لكل ورشة، السعر أدنى مسموح بيه (الـ multi-booking):

    الورشة السعر العادي أدنى سعر
    المحاسب المالي 3250 3000
    إعداد القوائم 2500 2000
    خبير الضرائب 5250 5000
    Odoo 3000 3000 (= السعر العادي)
    هندسة التكاليف 3500 3200
    التحليل المالي 5000 4000
    المدير المالي 6000 6000 (= السعر العادي)

    ممنوع نزول تحت أدنى سعر

    أدنى سعر مسموح بيه = الـ multi-booking. ممنوع النزول تحته بدون موافقة Director.

    ❌ ما تقولش: "هخصملك" ✅ قول: "بما إنك بتحجز أكتر من ورشة، عندنا package pricing"

    ❌ قواعد ممنوعة (Make no mistake)¶

    1. ممنوع خصم individual بدون شرط (مجموعة / fresh / early bird)
    2. ممنوع النزول تحت سعر الـ multi-booking
    3. ممنوع وعد بـ "خصم خاص" قبل الموافقة من Director
    4. ممنوع ذكر "فرع الإسكندرية" — هو مكان حضور استثنائي فقط
    5. ممنوع ذكر المحاسب الشامل بـ "كورس" — هي ورشة (الـ Udemy version برضو ورشة مسجّلة)
    6. ممنوع النسخة المسجلة بـ تقسيط
