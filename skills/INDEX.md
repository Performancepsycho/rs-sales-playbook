# RS Sales — Skills Index

> سكيلز جاهزة للاستخدام في شغل السيلز.
> طريقة الاستخدام: قول لكلود "استخدم سكيل X" أو "اشتغل بـ X" — هيتبع الإطار.

---

## فلسفة السكيلز

- **Community Skills:** universal frameworks مسحوبة من ريبوهات GitHub موثوقة. مكتوبة بالإنجليزي. الإطار universal، طبقه على RS بـ المثال.
- **Custom Skills:** مفصلة على RS تحديداً. مكتوبة بالعربي/مصري. تستخدم مصطلحات RS وتاريخ الورش.

**القاعدة:** لو الطلب عام → community. لو الطلب RS-specific → custom.

## القاعدة الذهبية للسكيلز

**ما تستخدمش سكيل لو الطلب أبسط من كده.** السكيل بيشتغل لما الطلب فيه:
- أكتر من output type (مثلاً: حساب + pitch + objections)
- محتاج framework محدد
- تكرار محتمل (هتستخدمه أكتر من مرة)

**لو الطلب One-shot بسيط:** ما تحتاجش سكيل، اعمله مباشرة.
